### 오늘의 한 줄

AI로 글을 쓰는 건 문제가 아닙니다. **AI가 쓴 티가 나는 게** 문제입니다. 오늘은 네이버가 내 글을 어떤 순서로 보는지, 어디서 AI 글을 걸러내는지, 그리고 **어디까지 자동화하고 어디부터 사람이 손대야 하는지**를 정합니다.

### 오늘 끝나면 이걸 할 수 있습니다

- 네이버가 글을 수집·분석·평가하는 3단계를 설명할 수 있다
- C-Rank와 D.I.A.가 각각 무엇을 보는지 구분할 수 있다
- AI 글이 걸리는 4가지 지점을 알고 피할 수 있다
- 'AI 60% + 사람 40%' 원칙으로 글을 다듬을 수 있다
- 네이버 AI 브리핑에 인용되기 쉬운 구조로 쓸 수 있다

> ⚠️ **먼저 읽어주세요** — 이 자료에는 **네이버가 공식으로 밝힌 것**과 **업계에서 경험적으로 통용되는 추정**이 섞여 있습니다. 어느 쪽인지 각 항목에 표시했고, 맨 아래 [PART 7](#part-7-어디까지가-확인된-사실인가)에 한 번 더 정리했습니다. 추정을 사실처럼 가르치면 수강생이 잘못된 확신을 갖게 됩니다.

## PART 1. 네이버는 내 글을 어떤 순서로 보는가

글을 발행하면 세 단계를 거칩니다.

| 단계 | 무슨 일이 일어나나 |
| --- | --- |
| **① 수집** | 네이버 웹수집 로봇(**Yeti**)이 본문 텍스트, HTML 구조, 이미지 정보를 가져갑니다 |
| **② 분석** | 한국어 형태소 분석기로 키워드·문장 구조를 뜯어보고, **기존 문서 수억 건과 대조**해 유사 문서인지 판별합니다 |
| **③ 평가** | **C-Rank**(출처가 믿을 만한가)와 **D.I.A.**(이 문서가 좋은가)로 순위를 매깁니다 |

> 🔑 **핵심** — ②단계의 **유사 문서 판별**이 AI 글의 첫 번째 관문입니다. 웹에 있는 글을 요약·재가공만 한 AI 글은 여기서 걸립니다. 순위가 밀리는 게 아니라 **아예 검색에서 빠집니다(검색 누락).**

## PART 2. C-Rank와 D.I.A. 제대로 알기

### 2-1. 둘은 보는 대상이 다릅니다

| | **C-Rank** | **D.I.A.** |
| --- | --- | --- |
| 무엇을 보나 | **누가 썼나** (출처) | **이 글이 어떤가** (문서) |
| 판단 기준 | 블로그 전체의 신뢰도 | 글 한 편의 품질 |
| 쌓이는 데 | 오래 걸림 | **한 편으로도 가능** |
| 신규 블로그 | 불리함 | ⭐ **기회** |

> 💡 **신규 블로그의 희망** — C-Rank가 낮아도, D.I.A.는 **글 한 편이 좋으면 상위 노출 기회를 줍니다.** 오래된 블로그를 이기는 유일한 길이 여기입니다.

### 2-2. C-Rank — 출처 신뢰도

블로그가 **특정 분야의 믿을 만한 출처**인지를 봅니다. 네이버가 설명하는 세 가지 축입니다.

| 축 | 뜻 | 실무에서는 |
| --- | --- | --- |
| **Context** | 주제의 일관성 | 한 분야로 꾸준히 쓰기. 오늘 맛집, 내일 주식 ❌ |
| **Content** | 활동 기간과 글의 연계성 | 오래, 꾸준히 |
| **Chain** | 방문자 반응(댓글·공감 등) | 사람이 실제로 읽고 반응하는가 |

> 📌 **용어 주의** — 'C-Rank = Creator Rank'라는 설명이 실무에서 널리 쓰이지만, **네이버 공식 문서가 약자를 그렇게 풀어 쓴 것은 아닙니다.** 네이버는 "**출처**의 신뢰도와 인기도를 평가하는 알고리즘"이라고 설명합니다. 뜻은 통하니 그렇게 이해하되, 강의에서 "공식 명칭"이라고 단정하지는 마세요.

### 2-3. D.I.A. — 문서 품질

**D**eep **I**ntent **A**nalysis, **심층 의도 분석**입니다. 검색한 사람의 의도를 이 문서가 얼마나 충족하는지를 봅니다.

**네이버가 밝힌 D.I.A. 평가 요소 7가지**

| # | 요소 | 쉽게 말하면 |
| --- | --- | --- |
| 1 | 문서의 주제 적합도 | 제목과 내용이 맞는가 |
| 2 | **경험 정보** | ⭐ 직접 겪은 이야기가 있는가 |
| 3 | 정보의 충실성 | 알맹이가 있는가 |
| 4 | 문서의 의도 | 정보를 주려는 글인가, 광고인가 |
| 5 | 상대적인 어뷰징 척도 | 꼼수를 썼는가 |
| 6 | **독창성** | ⭐ 남의 글과 다른가 |
| 7 | 적시성 | 지금 유효한 정보인가 |

> 🎯 **2번과 6번이 AI 글의 급소입니다.** AI는 지식은 잘 정리하지만 **내가 겪은 것**과 **나만 쓸 수 있는 것**을 만들지 못합니다.

> ⚠️ 이 7가지는 **품질 가이드라인이지 고정된 공식이 아닙니다.** 네이버는 검색 데이터를 딥러닝으로 학습하며 기준을 계속 갱신합니다.

## PART 3. 네이버가 감지하는 AI 글 4대 위험 요소

### ① AI 특유의 문체와 상투어

이런 문장들은 **양산형 기계 생성 텍스트**로 분류되기 쉽습니다.

| ❌ 이런 문장 | 왜 |
| --- | --- |
| "오늘은 ○○에 대해 함께 알아보는 시간을 갖겠습니다" | 정해진 도입 공식 |
| "현대 사회에서 ○○는 중요한 요소로 자리 잡고 있습니다" | 아무 내용 없는 서론 |
| "첫째, 둘째, 셋째… 결론적으로" | 기계적인 나열 |
| `따라서` `결론적으로` `뿐만 아니라` 남발 | 접속어 쌓기 |
| 감정이 없는 서술어 | 사람이 안 쓰는 말투 |

> 🔗 이 패턴을 한국어 기준 15가지로 정리한 자료가 [[05강_AI티 없애는 글쓰기 규칙과 나만의 스킬 만들기]]입니다. 오늘 배운 내용과 함께 보세요.

### ② 경험(맥락)의 부재 — D.I.A. 감점

AI는 **"내가 실제로 겪은 구체적 디테일"**을 만들어내지 못합니다.

| ❌ AI가 쓰는 문장 | ⭕ 사람만 쓸 수 있는 문장 |
| --- | --- |
| 주차장이 넓습니다 | **지하 2층 B구역**에 대면 엘리베이터가 바로 나와서 편했습니다 |
| 가격이 합리적입니다 | 2인 **34,000원** 나왔고, 공깃밥은 별도 1,000원이었습니다 |
| 대기가 있을 수 있습니다 | 토요일 **12시 20분** 도착해서 **25분** 기다렸습니다 |
| 직원이 친절합니다 | 유아용 의자를 묻기 전에 먼저 가져다주셨습니다 |

**구체적 맥락 4종 세트** — 시간 / 위치 / 체감 감정 / 실패담

> 이게 없으면 잠깐 상위에 올라도 **체류 시간 부족으로 금방 밀려납니다.**

### ③ 무료 스톡 이미지·AI 이미지 남발

- Unsplash·Pixabay 같은 무료 이미지는 **이미 수천 개 문서에 똑같이 들어가 있습니다.** 신선도 점수가 깎입니다
- 사진이 없거나 남들과 똑같은 이미지만 쓴 글은 **이미지 검색 탭에서도 빠집니다**

### ④ 지나치게 빠르고 규칙적인 발행

**매일 정확히 같은 시각**, 또는 **1시간 간격**으로 올리는 행위는 사람의 패턴이 아닙니다. 자동화 프로그램으로 의심받기 쉽습니다.

## PART 4. 자동화·임시저장이 위험해지는 3대 지점

> 📌 [[06강_사진 넣으면 블로그 글이 완성되는 자동화 툴 만들기]]에서 만든 것 같은 **임시저장 자동화**를 쓴다면 이 파트를 반드시 읽으세요.

### ① 에디터 행동 데이터

- 자동화 브라우저는 `navigator.webdriver`라는 표식을 남깁니다. 이걸 감지한다는 것이 업계의 일반적인 이해입니다
- 마우스 움직임, 타이핑 속도, **에디터에 머문 시간** 없이 스크립트로 순식간에 채워 넣으면 **'매크로 의심 계정'**으로 분류될 수 있습니다

> 🛡️ **그래서 이렇게** — 자동화로 임시저장까지만 하고, **사람이 에디터를 열어 실제로 몇 분간 고칩니다.**

### ② 텍스트 패턴

PART 3의 ①②와 같습니다. 웹에 있는 문서를 요약·재가공한 AI 글은 **유사 문서로 분류되어 첫 페이지에서 즉시 누락**됩니다.

### ③ 미디어·메타데이터 결여

직접 찍은 사진에는 **EXIF**라는 정보가 붙어 있습니다.

| EXIF에 담기는 것 | 예 |
| --- | --- |
| 촬영 기기 | iPhone 15 |
| 촬영 일시 | 2026-09-04 12:31 |
| 위치(설정 시) | GPS 좌표 |

AI 자동화로는 이걸 만들어낼 수 없습니다. **텍스트만 빽빽하거나 스톡 이미지만 있는 글**은 D.I.A. 점수가 낮게 매겨집니다.

## PART 5. 안전한 AI 자동화 파이프라인 ⭐

### 5-1. 자동화 범위를 한정합니다

```
[자동화 O]  초안 생성 → 기본 텍스트 채우기 → 임시저장  ← 여기서 멈춤
[사람 O]    사진 추가 → 텍스트 윤문 → 검수 → 발행
```

> **자동 발행은 하지 않습니다.** 발행 버튼은 항상 사람이 누릅니다.

### 5-2. 발행 전 필수 휴먼 터치 3가지

| # | 할 일 | 기준 |
| --- | --- | --- |
| **1** | **사진 추가** | 직접 찍은 원본 사진 **3~5장**을 글 중간에 배치하고 캡션 달기 |
| **2** | **텍스트 윤문** | **20% 이상 수정.** AI 상투어를 지우고 문단마다 내 경험 1~2줄 직접 타이핑 |
| **3** | **체류 시간 확보** | 임시저장 글을 열고 **최소 3~5분** 수정한 뒤 발행 |

### 5-3. 'AI 60% + 휴먼 터치 40%' 원칙

| 위치 | 사람이 할 일 |
| --- | --- |
| **도입부 2~3줄** | 오늘 내 상황, 이 글을 쓰게 된 계기를 **직접 손으로** 칩니다 |
| **본문 중간 2~3군데** | "실제로 써보니 ○○은 좀 아쉬웠다", "결제할 때 카카오페이는 안 되더라" 같은 실사용 팁 |
| **서론·결론** | AI가 쓴 지루한 개요와 "도움이 되셨길 바랍니다"류는 **전부 삭제**하고 본론으로 바로 |

### 5-4. 사진 다루기

- **직접 촬영한 사진 3장 이상**을 배치합니다. EXIF가 붙어 있어 신뢰도가 올라갑니다
- **스크린샷을 쓸 때는** 캔바나 그림판에서 테두리·화살표·텍스트 강조를 추가해 **재가공된 이미지**로 만드세요

### 5-5. 키워드 반복 강박 버리기

> 예전 방식대로 키워드를 5회, 7회씩 억지로 반복하면 **키워드 스터핑으로 감점**됩니다.

**제목에 한 번, 본문에는 문맥에 맞게 2~3회**면 충분합니다. 형태소 분석기가 연관 단어들을 함께 묶어 파악합니다.

### 5-6. 발행 주기

| 항목 | 권장 |
| --- | --- |
| 에디터 편집 시간 | 글 1편당 **최소 5분 이상** |
| 하루 발행 수 | **1~2편** |
| 시각 | 매일 똑같은 분 단위 ❌ → **분산** |
| 임시저장이 쌓였을 때 | 몰아서 연속 발행 ❌ → 간격 두기 |

## PART 6. 네이버 AI 브리핑에 인용되게 하기

네이버 AI 브리핑은 웹 문서를 실시간으로 탐색·요약해 답을 제시하고, **출처 링크를 붙입니다.** 여기에 인용되면 검색 순위와 별개로 노출됩니다.

### 6-1. AI 브리핑이 문서를 고르는 4가지 기준

| 기준 | 뜻 |
| --- | --- |
| **최신성·출처 신뢰도** | 잘못된 답을 줄이려고 검증된 고신뢰 출처를 우선합니다 |
| **검색 의도 일치** | 키워드 매칭이 아니라, **질문에 대한 답 문장이 들어 있는 단락**을 찾습니다 |
| **기계가 읽기 쉬운 구조** | 소제목, 목록, 표로 정리된 문서를 우선 고릅니다 |
| **직접 경험·고유 맥락** | 흔한 일반론은 AI가 알아서 답하고, **오리지널 요소가 있는 문서**를 출처로 인용합니다 |

### 6-2. 실전 작성 팁 3가지

**① 질문형 소제목 + 2~3줄 두괄식 답변**

소제목 아래에 서론을 길게 쓰지 말고, **바로 결론을 2~3문장**으로 제시하세요. 그 단락이 통째로 요약 답변의 근거가 됩니다.

```
❌  ## 주차 안내
    이 가게를 방문하시는 분들이라면 주차가 궁금하실 텐데요…

⭕  ## 주차는 어디에 하나요?
    건물 지하 1~3층에 주차장이 있고, 2시간 무료입니다.
    만차일 때는 길 건너 공영주차장(10분 300원)을 쓰면 됩니다.
```

**② 비교·정리는 표와 목록으로**

빽빽한 줄글보다 **행과 열로 구분된 표**(가격, 스펙, 장단점)를 훨씬 잘 가져갑니다.

**③ 구체적 고유명사와 수치**

| ❌ 추상적 | ⭕ 구체적 |
| --- | --- |
| 비용이 저렴했습니다 | 입장료 성인 **15,000원**, 주차 **2시간 무료** |

> 🔗 이 원리는 구글에서도 같습니다. [[01강_디지털마케팅의 변화와 기회(SEO에서 GEO로)]]와 함께 보세요.

## PART 7. 어디까지가 확인된 사실인가

이 구분을 수강생에게 꼭 알려주세요. **추정을 사실처럼 가르치면 안 됩니다.**

| 내용 | 상태 |
| --- | --- |
| C-Rank가 출처 신뢰도를, D.I.A.가 문서 품질을 평가한다 | ⭕ **네이버 공식** |
| D.I.A. = Deep Intent Analysis (심층 의도 분석) | ⭕ **공식** |
| D.I.A. 평가 요소 7가지 | ⭕ **네이버가 밝힌 가이드라인** (고정 공식은 아님) |
| C-Rank의 Context·Content·Chain | ⭕ **공식 설명** |
| 'C-Rank = Creator Rank' 약자 풀이 | ⚠️ **업계 통용 표현.** 공식 약자 풀이 아님 |
| 유사 문서로 판별되면 검색에서 누락된다 | ⭕ 널리 확인된 현상 |
| `navigator.webdriver` 감지, 에디터 입력 로그 수집 | ⚠️ **업계 추정.** 네이버가 공개한 바 없음 |
| 하루 1~2편 / 5분 이상 편집 같은 구체적 수치 | ⚠️ **경험적 권장치.** 공식 기준 아님 |
| 'AI 60% + 사람 40%' 비율 | ⚠️ **경험 법칙.** 측정 기준 없음 |
| AI 브리핑 노출 점수 = (C-Rank×W₁)+(D.I.A.+×W₂)+(RAG 적합도×W₃) | ⚠️ **개념 설명용 비유.** 네이버가 발표한 공식이 아님 |

> 💬 **그래도 지킬 가치가 있는 이유** — 위 ⚠️ 항목들은 공식이 아니지만, **지켜서 손해 볼 것이 하나도 없습니다.** 직접 찍은 사진을 넣고, 내 경험을 쓰고, 하루 한두 편만 올리는 건 알고리즘과 무관하게 **좋은 블로그의 조건**이기도 합니다.
