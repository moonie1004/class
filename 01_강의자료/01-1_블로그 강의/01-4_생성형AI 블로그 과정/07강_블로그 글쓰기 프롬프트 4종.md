### 오늘의 한 줄

블로그를 쓰다 보면 늘 같은 데서 막힙니다. **어떤 키워드로 쓸지, 어떻게 시작할지, 왜 금방 나가는지.** 오늘은 그 네 가지 막힘을 각각 뚫어주는 프롬프트 4개를 순서대로 씁니다.

### 오늘 끝나면 이걸 할 수 있습니다

- 경쟁 적은 키워드를 20개 뽑아 우선순위를 매길 수 있다
- 독자가 끝까지 읽는 글의 뼈대를 먼저 설계할 수 있다
- 900~1,200자 포스팅 초안과 제목 후보 5개를 받을 수 있다
- 블로그 프로필 소개글을 5가지 버전으로 만들 수 있다
- AI 결과가 마음에 안 들 때 **다시 시키지 않고 고쳐 쓰는 법**을 안다
- 한 번에 완성본까지 뽑는 **통합 마스터 프롬프트**를 쓸 수 있다

## PART 0. 오늘의 큰 그림 — 한 번에 다 시키지 마세요

가장 흔한 실수가 **"블로그 글 하나 써줘"라고 한 번에 부탁하는 것**입니다. 그러면 키워드도 어정쩡하고 구조도 밋밋한 글이 나옵니다.

오늘은 **네 번에 나눠서** 시킵니다.

| STEP | 프롬프트 | 무엇이 나오나 |
| --- | --- | --- |
| 1 | ① 키워드 발굴 | 공략할 키워드 20개 + 우선순위 |
| 2 | ② 글 구조 설계 | 도입부 훅·소제목·본문 흐름 |
| 3 | ③ 포스팅 초안 | 900~1,200자 글 + 제목 후보 5개 |
| 4 | (사람이) 내 말투로 수정 | 내 경험·사진·가격·장단점 추가 |

> 💬 **④번 프로필 소개글**은 글쓰기 흐름과 별개로, 블로그를 처음 세팅할 때 한 번 쓰는 프롬프트입니다.

### ⚠️ 시작 전 꼭 알아둘 것

**AI는 네이버의 실시간 검색량이나 정확한 경쟁도를 확인하지 못합니다.** 그래서 ①번 프롬프트에는 "수치를 확인할 수 없으면 임의로 만들지 말고 **'추정'이라고 표시하라**"는 조건이 들어가 있습니다. 정확한 숫자가 필요하면 **키워드 분석 도구의 실제 자료를 함께 넣어주고** 분석을 시켜야 합니다.

## PART 1. ① 상위노출 키워드 발굴 프롬프트

### 언제 쓰나

글을 쓰기 **전에**, 어떤 키워드를 공략할지 정할 때.

### 왜 필요한가

무작정 인기 키워드만 쓰면 이미 경쟁이 치열해서 상위노출이 어렵습니다. 메인 키워드뿐 아니라 **구체적인 롱테일 키워드와 검색 의도**까지 같이 봐야 합니다.

> 🌾 **롱테일 키워드란?** — "맛집"이 아니라 "부천 아이랑 갈만한 브런치 맛집"처럼 **길고 구체적인 검색어**입니다. 찾는 사람은 적지만 경쟁도 적고, 그만큼 **정확히 그걸 찾는 사람**이 들어옵니다.

### 프롬프트

```
너는 네이버 블로그 키워드 전략을 설계하는 콘텐츠 마케터야.

내가 운영하는 블로그 정보는 다음과 같아.

- 블로그 주제: [주제 입력]
- 주요 독자: [타깃 입력]
- 현재 블로그 규모: [초보/성장 중/운영 기간 입력]
- 작성하려는 글의 목적: [정보 제공/방문 후기/상품 소개/상담 유도]
- 지역 키워드 사용 여부: [지역명 또는 사용하지 않음]

위 정보를 바탕으로 네이버 블로그에서 활용할 수 있는 키워드를 분석해줘.

다음 항목을 포함해 표로 정리해줘.

1. 메인 키워드
2. 세부 롱테일 키워드
3. 예상 경쟁도
4. 검색하는 사람의 의도
5. 추천 콘텐츠 유형
6. 제목에 활용할 수 있는 문장
7. 초보 블로그의 공략 우선순위

조건:
- 너무 넓고 경쟁이 강한 키워드는 제외해줘.
- 검색자의 상황이 구체적으로 드러나는 키워드를 우선 추천해줘.
- 구매, 방문, 신청, 비교처럼 행동으로 이어질 가능성이 높은 키워드도 포함해줘.
- 총 20개를 추천해줘.
- 실제 검색량이나 경쟁도를 확인할 수 없다면 임의의 수치를 만들지 말고 '추정'이라고 표시해줘.
```

### 이렇게 넣으면 됩니다 (주제 예시)

- 엄마표 독서
- 제주도 아이와 가볼 만한 곳
- 직장인 부업 추천
- 신혼부부 가계부 작성법

## PART 2. ② 체류시간을 높이는 글 구조 프롬프트

### 언제 쓰나

본문을 쓰기 **전에** 뼈대를 먼저 잡을 때.

### 왜 필요한가

좋은 정보가 있어도 **흐름이 어색하면 독자가 금방 나갑니다.** 도입부 → 공감 → 정보 → 경험 → 결론 순서로 뼈대부터 세우세요.

### 프롬프트

```
너는 네이버 블로그 콘텐츠의 구조와 독자 체류시간을 개선하는 전문 에디터야.

작성할 글의 정보는 다음과 같아.

- 핵심 키워드: [키워드]
- 글의 주제: [주제]
- 주요 독자: [타깃]
- 글의 목적: [정보 제공/후기 전달/상담 유도/상품 소개]
- 내가 전달하고 싶은 핵심 내용: [핵심 내용]
- 포함할 실제 경험 또는 사례: [경험 입력]

위 내용을 바탕으로 독자가 끝까지 읽기 쉬운 블로그 글 구조를 만들어줘.

다음 요소를 포함해줘.

1. 첫 문장에서 관심을 끄는 도입부 훅 3개
2. 독자의 상황을 건드리는 공감 질문 3개
3. 문제를 구체적으로 보여주는 내용
4. 해결 방법을 단계별로 설명하는 본문
5. 신뢰도를 높이는 실제 경험 또는 사례
6. 독자가 궁금해할 만한 FAQ
7. 핵심 내용을 정리하는 결론
8. 댓글, 저장, 문의 중 글의 목적에 맞는 CTA

추가 조건:
- 과장되거나 자극적인 표현은 줄여줘.
- 같은 말을 반복하지 않게 구성해줘.
- 각 문단에 어울리는 소제목도 함께 작성해줘.
- 모바일에서 읽기 쉽도록 문단을 짧게 나눠줘.
- 키워드는 문맥에 맞게 자연스럽게 배치해줘.
```

### 업종에 맞게 흐름을 바꿔도 됩니다

맛집 후기라면 이렇게 요청할 수 있습니다.

다음 흐름으로 글의 구조를 만들어줘.

- 방문 전 고민했던 점
- 방문하게 된 이유
- 위치와 주차 정보
- 메뉴와 가격
- 직접 먹어본 솔직한 후기
- 장점과 아쉬운 점
- 어떤 사람에게 추천하는지
- 재방문 의사
- 댓글을 유도하는 마무리 문장
```

## PART 3. ③ 네이버 블로그 포스팅 초안 프롬프트

### 언제 쓰나

시간이 없거나, 처음부터 쓰기 막막할 때.

### 프롬프트

```
너는 네이버 블로그 콘텐츠를 전문적으로 작성하는 작가야.

아래 정보를 참고해서 네이버 블로그 포스팅을 작성해줘.

- 나의 직업 또는 정체성: [입력]
- 블로그의 주요 타깃: [입력]
- 핵심 키워드: [입력]
- 글의 목적: [정보 제공/후기 공유/상담 및 문의 유도]
- 원하는 말투: [친근한 존댓말/솔직한 후기형/전문적인 설명형]

작성 조건:
- 분량은 900~1,200자
- 독자가 공감할 수 있는 도입부로 시작
- 핵심 키워드를 제목과 본문에 자연스럽게 반영

- 내용에 맞는 소제목 3~4개 포함
- 지나치게 광고처럼 보이는 표현은 제외
- 실제 블로거가 작성한 것처럼 자연스러운 말투 사용
- 마지막에는 댓글, 상담 또는 문의로 이어지는 CTA 포함
- 제목 후보도 5개 추천
```

- 원하는 말투: 친근하고 솔직한 존댓말

작성 조건:

## PART 4. ④ 블로그 프로필 소개글 프롬프트

### 언제 쓰나

블로그를 처음 세팅할 때, 또는 방향을 바꿨을 때 한 번.

### 왜 필요한가

프로필은 길게 쓰는 게 아니라, **누구에게 어떤 정보를 주는 블로그인지 바로 이해되게** 만드는 게 중요합니다.

### 프롬프트

```
너는 퍼스널 브랜딩과 블로그 소개글을 전문적으로 작성하는 작가야.

아래 정보를 활용해서 네이버 블로그 프로필 소개글을 만들어줘.

- 블로그 주제: [여행/맛집/육아/일상/재테크/부업 등]
- 주요 독자: [30대 주부/직장인/커플/초보 창업자 등]
- 운영 목적: [기록/정보 공유/수익화/브랜딩/상담]
- 나의 경험: [관련 경력이나 시작하게 된 계기]
- 나만의 특징: [솔직한 후기/꼼꼼한 정리/가성비 정보 등]
- 독자에게 제공할 가치: [블로그를 보면 얻을 수 있는 것]
- 연락 방법: [댓글/쪽지/이메일/외부 링크]

작성 조건:
- 200자 이내로 작성해줘.
- 자연스럽고 진솔한 존댓말을 사용해줘.
- 지나친 자기 자랑이나 과장은 피해야 해.
- 블로그의 주제와 대상이 바로 드러나게 해줘.
- 나의 경험과 차별점이 자연스럽게 느껴지게 해줘.
- 마지막에는 소통 또는 문의를 안내하는 문장을 넣어줘.
- 분위기가 서로 다른 버전 5개를 만들어줘.

버전 구성:
1. 친근한 소개형
2. 신뢰감을 주는 전문형
3. 경험을 강조한 스토리형
4. 짧고 명확한 핵심형
5. 소통을 강조한 커뮤니티형
```

## PART 5. 결과가 마음에 안 들 때 — 다시 시키지 말고 고치세요

가장 아까운 습관이 **"처음부터 다시 써줘"**입니다. 이미 나온 결과에서 **고칠 부분만 콕 집어** 말하는 게 훨씬 빠르고 결과도 좋습니다.

### 그대로 복사해서 쓰는 수정 요청 8가지

| 이럴 때 | 이렇게 말하세요 |
| --- | --- |
| 문장이 딱딱함 | 문장이 너무 딱딱해. 친근한 존댓말로 바꿔줘. |
| 도입이 지루함 | 도입부를 더 짧고 궁금하게 만들어줘. |
| 광고 티가 남 | 광고처럼 느껴지는 표현을 삭제해줘. |
| 내 얘기가 안 보임 | 내 경험이 더 잘 드러나도록 수정해줘. |
| 모바일에서 답답함 | 문단을 모바일에서 읽기 쉽게 나눠줘. |
| 같은 말 반복 | 같은 표현이 반복되지 않게 다듬어줘. |
| 마무리가 늘어짐 | 결론을 3줄로 짧게 정리해줘. |
| 마지막 권유가 부담스러움 | CTA가 부담스럽지 않도록 자연스럽게 바꿔줘. |

> 프롬프트를 한 번에 완벽하게 쓰려고 고민하지 마세요. **먼저 초안을 만들고, 대화하면서 한 부분씩 고쳐나가는 것**이 훨씬 자연스러운 결과를 만듭니다.

## PART 6. ⚠️ 꼭 기억해 주세요

**AI가 만든 글을 그대로 복사해서 발행한다고 상위노출이 보장되지 않습니다.**

좋은 블로그 글에는 여전히 이런 것들이 필요합니다.

| 필요한 것 | AI가 대신해 주나 |
| --- | --- |
| 직접 경험한 내용 | ❌ 내가 줘야 함 |
| 실제로 촬영한 사진 | ❌ 내가 찍어야 함 |
| 독자에게 도움 되는 구체적 정보 | △ 내가 확인해야 함 |
| 자연스러운 문장과 나만의 말투 | △ 내가 다듬어야 함 |
| 제목과 본문 내용의 일치 | ⭕ 확인만 하면 됨 |
| 꾸준한 작성과 기존 글 관리 | ❌ 내가 해야 함 |

> **AI는 블로그를 대신 운영해 주는 도구가 아니라, 막막했던 시작을 빠르게 만들어 주는 보조 도구입니다.**

## PART 7. 한 단계 위 — 통합 마스터 프롬프트

앞의 4종은 **단계별로 나눠 쓰는** 프롬프트입니다. 익숙해지면 **한 번에 완성본까지 뽑는** 통합 프롬프트를 쓸 수 있습니다.

### 7-1. 4종에 없던 것 — 새로 배우는 8가지

| # | 새 항목 | 4종과 무엇이 다른가 |
| --- | --- | --- |
| 1 | 검색 의도를 9종으로 분류 | 4종은 "검색 의도"라고만 함. 여기선 유형을 정해 초반부터 답하게 함 |
| 2 | **장점과 단점**을 본문 구조에 필수 포함 | 한쪽으로 치우친 홍보글이 되는 걸 구조로 막음 |
| 3 | **경험이 없을 때의 대체 표현** | 4종은 "경험을 넣어라"까지. 없을 때 어떻게 쓰는지가 새로움 |
| 4 | 근거 없는 정보에 쓸 완충 표현 5개 | 지어내기를 막는 구체적 문장 |
| 5 | **광고 금지 표현 7개** | "무조건·100%·최고의·업계 1위" 등. 표시광고법과도 직결 |
| 6 | 사진 삽입 위치 표기법 | `[사진 1: …]`로 원고에 자리를 잡아줌 |
| 7 | **최종 검수 12문항** | AI가 스스로 검토하고 **최종본만** 출력 |
| 8 | 출력 형식 고정 | 제목 후보·본문·키워드·해시태그·**썸네일 문구**까지 한 번에 |

### 7-2. 검색 의도 9종 — 내 키워드는 어디에 속하나

| 유형 | 검색자가 원하는 것 | 예시 키워드 |
| --- | --- | --- |
| 정보 탐색 | 그게 뭔지 알고 싶다 | "젤네일 지속기간" |
| 문제 해결 | 지금 겪는 문제를 없애고 싶다 | "네일 들뜸 원인" |
| 비교 | 둘 중 뭐가 나은지 | "젤네일 vs 일반네일" |
| 추천 | 뭘 골라야 하나 | "잠실 네일샵 추천" |
| 후기 확인 | 실제로 어떤지 | "○○네일 후기" |
| 구매 검토 | 살까 말까 | "홈케어 젤네일 키트" |
| 가격 확인 | 얼마인가 | "젤네일 가격" |
| 업체·장소 탐색 | 어디로 갈까 | "잠실역 근처 네일" |
| 방문 전 정보 확인 | 가기 전에 알아둘 것 | "네일샵 예약 방법" |

> 💬 **왜 중요한가** — 유형이 정해지면 **글 첫머리에 뭘 써야 할지가 정해집니다.** '가격 확인'인데 가게 소개부터 하면 독자는 나갑니다.

### 7-3. 경험이 없을 때는 이렇게

AI에게 "직접 해본 것처럼 써줘"라고 시키면 **없는 경험을 지어냅니다.** 이건 독자를 속이는 거예요. 마스터 프롬프트에는 이 규칙이 들어 있습니다.

| 상황 | 이렇게 씁니다 |
| --- | --- |
| 내가 실제로 해봤다 | 그 경험을 구체적으로 (날짜·가격·불편했던 점) |
| 안 해봤다 | ❌ 지어내지 말고 → ⭕ **"일반적으로 확인해야 할 기준은 다음과 같습니다"** |

### 7-4. 근거가 확실하지 않을 때 쓰는 완충 표현 5개

숫자·통계·정책·가격은 **확인된 것만** 씁니다. 확실하지 않으면 단정하지 말고 이렇게.

- 상황에 따라 달라질 수 있습니다.
- 업체별로 차이가 있을 수 있습니다.
- 정확한 내용은 공식 안내를 확인하는 것이 좋습니다.
- 제공된 자료를 기준으로 보면…
- 현재 확인 가능한 정보 기준으로…

> ⚠️ **건강·의료·법률·금융** 주제는 특히 조심하세요. 과장된 표현을 쓰면 안 됩니다.

### 7-5. 쓰면 안 되는 광고 표현 7개

| ❌ 금지 | 왜 |
| --- | --- |
| 무조건 / 100% | 근거를 댈 수 없는 단정 |
| 최고의 / 완벽한 | 비교 기준이 없는 최상급 |
| 반드시 효과가 있는 | 효과 보장은 위험한 표현 |
| 누구에게나 좋은 | 사실이 아님 |
| 업계 1위 | **객관적 근거가 있을 때만** 사용 가능 |

### 7-6. 광고성 글은 이 순서로

판매 문구를 처음부터 반복하면 독자가 바로 나갑니다.

```
문제 제시 → 정보 제공 → 해결 방법 → 제품·서비스 소개
→ 선택 이유 → 실제 장점 → 추천 대상 → 행동 유도
```

### 7-7. 최종 검수 12문항 — 발행 전 체크리스트

AI에게도 시키고, 나도 한 번 봅니다.

| # | 확인할 것 | ⬜ |
| --- | --- | --- |
| 1 | 검색자가 궁금한 내용에 실제로 답했는가? | ⬜ |
| 2 | 중요한 답이 너무 뒤에 나오지 않는가? | ⬜ |
| 3 | 제목과 본문 내용이 일치하는가? | ⬜ |
| 4 | 불필요하게 긴 서론은 없는가? | ⬜ |
| 5 | 같은 이야기를 반복하지 않았는가? | ⬜ |
| 6 | 키워드를 억지로 넣은 문장은 없는가? | ⬜ |
| 7 | 독자가 실제로 활용할 정보가 있는가? | ⬜ |
| 8 | 근거 없는 사실이나 경험을 만들어내지 않았는가? | ⬜ |
| 9 | 광고 문구가 지나치게 많지 않은가? | ⬜ |
| 10 | 읽은 후 다음 행동이 명확한가? | ⬜ |
| 11 | AI 같은 상투적 표현이 반복되지 않는가? | ⬜ |
| 12 | 모바일에서 문단이 적절히 나뉘어 있는가? | ⬜ |

> 11번은 [[05강_AI티 없애는 글쓰기 규칙과 나만의 스킬 만들기]]의 자가진단표와 함께 보면 훨씬 정확합니다.

### 7-8. 보조 키워드 넓히기 — 한 가지 예시

핵심 키워드가 `잠실 네일샵`이라면, 이런 관련 표현을 문맥에 맞게 섞습니다.

`잠실역 네일` · `잠실 젤네일` · `잠실 네일아트` · `잠실역 근처 네일샵` · `젤네일 디자인` · `네일 관리`

**같은 키워드를 의미 없이 반복하는 것과는 다릅니다.** 표현을 바꿔가며 자연스럽게 넣는 것이 목적이에요.

## [부록] 통합 마스터 프롬프트 — 복사해서 쓰세요

> 붙여넣은 뒤 **1번 입력 정보**만 내 상황으로 채우면 됩니다. 비워 둔 항목은 AI가 주제에 맞게 알아서 잡되, **사실관계는 임의로 만들지 않습니다.**

````
# 네이버 블로그 글쓰기 마스터 프롬프트

당신은 **네이버 블로그 콘텐츠 전문 작가이자 콘텐츠 마케팅 전문가**입니다.
사용자가 제공하는 주제, 키워드, 타겟 고객, 목적을 바탕으로
**검색을 통해 유입된 독자가 끝까지 읽고, 저장·공감·댓글·문의·구매·방문 등 다음 행동을 하도록 만드는 네이버 블로그 글**을 작성합니다.

단순히 키워드를 반복하는 SEO 글이 아니라,
**검색 의도를 정확히 충족하면서 실제 사람이 읽기 편하고 유용한 콘텐츠**를 작성하는 것이 가장 중요합니다.

## 1. 입력 정보

- 주제:
- 핵심 키워드:
- 보조 키워드:
- 제품/서비스:
- 타겟 독자:
- 지역:
- 글의 목적:
- 원하는 행동:
- 글의 톤:
- 작성자 경험 또는 전문성:
- 반드시 포함할 내용:
- 제외할 내용:
- 참고 자료:
- 목표 글자 수:

정보가 일부 제공되지 않은 경우에는 주제와 목적에 맞게 합리적으로 설정합니다.
단, 사실관계가 필요한 내용을 임의로 만들어내지 않습니다.

## 2. 글 작성 전 먼저 판단할 것

### ① 검색 의도
이 키워드를 검색한 사람이 가장 알고 싶은 것이 무엇인지 판단하고, 다음 중 하나 또는 복수로 구분합니다.
정보 탐색 / 문제 해결 / 비교 / 추천 / 후기 확인 / 구매 검토 / 가격 확인 / 업체 또는 장소 탐색 / 방문 전 정보 확인
검색자의 질문에 초반부터 답을 제시합니다.

### ② 타겟 독자
현재 어떤 상황인가? 어떤 고민이 있는가? 무엇이 불안한가? 무엇을 결정하려 하는가? 어떤 정보를 확인하면 행동할 가능성이 높아지는가?
글은 작성자가 하고 싶은 이야기가 아니라 **독자가 알고 싶은 순서**로 작성합니다.

### ③ 글의 목표
글을 읽은 후 독자가 취해야 할 핵심 행동을 하나 정합니다. (구매/방문/예약/문의/상담/다른 글 읽기/브랜드 기억/댓글/저장/공유)
본문 전체가 이 행동으로 자연스럽게 연결되도록 구성합니다.

## 3. 제목 작성 원칙

제목 후보를 5개 작성한 뒤 가장 적합한 제목을 하나 선택합니다.

- 핵심 키워드를 자연스럽게 포함합니다.
- 검색자가 원하는 결과를 예상할 수 있게 합니다.
- 과장하거나 낚시성 표현을 쓰지 않습니다.
- 숫자, 대상, 문제, 결과 등을 필요에 따라 활용합니다.
- 제목만 읽어도 내용이 예상되어야 합니다.
- 같은 단어를 불필요하게 반복하지 않습니다.

좋은 제목 구조 예시:
- [핵심 키워드] 직접 해보니 알게 된 5가지
- [핵심 키워드] 처음이라면 꼭 알아야 할 것
- [지역 + 서비스] 선택하기 전에 확인할 5가지
- [제품명] 사용 후기, 장점과 아쉬운 점
- [문제] 때문에 고민이라면 이렇게 해보세요
- [A vs B] 어떤 것을 선택해야 할까?

## 4. 도입부 작성 원칙

장황한 인사말 없이 다음 순서로 시작합니다.
1. 독자가 겪고 있는 상황 또는 문제
2. 독자가 궁금해할 핵심 질문
3. 이 글에서 얻을 수 있는 정보

핵심 내용을 숨기지 말고 초반에 일부 공개합니다.

## 5. 본문 구조

정보의 중요도에 따라 소제목으로 나눕니다. 주제에 맞게 변경 가능합니다.
문제 또는 상황 → 핵심 정보(가장 알고 싶어 하는 내용을 먼저) → 구체적인 방법 또는 기준 → 실제 사례 또는 경험 → **장점과 단점**(한쪽으로 치우친 홍보글이 되지 않게 한계·주의점도) → 이런 사람에게 추천 → 최종 정리 → 행동 유도

## 6. 문장 작성 스타일

- 한 문장을 지나치게 길게 쓰지 않습니다.
- 한 문단에는 하나의 메시지만 담습니다.
- 어려운 전문용어보다 쉬운 표현을 쓰고, 필요하면 바로 설명합니다.
- 같은 문장 구조를 계속 반복하지 않습니다.
- 불필요한 형용사와 과장 표현을 줄입니다.
- 말하듯 자연스럽지만 지나치게 가볍지 않게 씁니다.
- "~인데요", "~했어요", "~같아요"를 모든 문장에 반복하지 않습니다.
- AI가 작성한 것처럼 기계적으로 보이는 나열을 피합니다.
- 같은 의미를 반복해 글자 수를 늘리지 않습니다.

## 7. 키워드 사용 원칙

핵심 키워드는 억지 반복이 아니라 **독자가 읽었을 때 자연스러운 범위에서만** 사용합니다.
위치: 제목 / 도입부 / 주요 소제목 / 본문 / 결론
보조 키워드와 관련 표현도 자연스럽게 섞습니다. (예: 핵심 키워드가 "잠실 네일샵"이면 잠실역 네일, 잠실 젤네일, 잠실 네일아트, 잠실역 근처 네일샵, 젤네일 디자인, 네일 관리)
단, 동일한 키워드를 의미 없이 반복하지 않습니다.

## 8. 경험과 전문성 표현

가능하면 직접 경험 / 실제 사용 과정 / 비교 과정 / 시행착오 / 고객 질문 / 현장에서 자주 발생하는 문제 / 실제 사례 / 전문가 관점의 판단 기준을 포함합니다.
단, 사용자가 제공하지 않은 경험을 실제로 경험한 것처럼 만들어내지 않습니다.
실제 경험 정보가 없다면 "일반적으로 확인해야 할 기준은 다음과 같습니다"처럼 사실에 맞는 방식으로 표현합니다.

## 9. 신뢰성을 높이는 방법

숫자, 통계, 정책, 가격, 연구 결과 등 검증이 필요한 정보는 근거 없이 만들어내지 않습니다.
자료가 제공된 경우 해당 자료를 우선 사용하고, 확인되지 않은 정보는 단정하지 않습니다.
다음 표현을 적절히 활용합니다.
- 상황에 따라 달라질 수 있습니다.
- 업체별로 차이가 있을 수 있습니다.
- 정확한 내용은 공식 안내를 확인하는 것이 좋습니다.
- 제공된 자료를 기준으로 보면
- 현재 확인 가능한 정보 기준으로

건강, 의료, 법률, 금융 등의 내용은 특히 과장된 표현을 사용하지 않습니다.

## 10. 광고성 글 작성 원칙

제품이나 서비스를 홍보하는 글이라도 처음부터 판매 문구를 반복하지 않습니다.
문제 제시 → 정보 제공 → 해결 방법 → 제품 또는 서비스 소개 → 선택 이유 → 실제 장점 → 추천 대상 → 행동 유도

다음과 같은 근거 없는 표현은 피합니다. (객관적 근거가 있을 때만 사용)
무조건 / 100% / 최고의 / 완벽한 / 반드시 효과가 있는 / 누구에게나 좋은 / 업계 1위

## 11. 지역 기반 콘텐츠

지역 키워드가 포함된 경우 실제로 도움이 되는 내용을 활용합니다.
지역명 / 역 또는 주요 교통수단 / 접근 방법 / 주변 랜드마크 / 주차 / 영업시간 / 예약 방법 / 주변 시설 / 방문하기 좋은 상황
단, 제공되지 않은 주소, 주차 정보, 영업시간 등을 임의로 만들지 않습니다.

## 12. 사진 삽입 위치 제안

사진이 있으면 좋을 위치에 다음과 같이 표시합니다.
[사진 1: 매장 외관 또는 대표 이미지]
[사진 2: 제품 사용 과정]
[사진 3: Before / After 비교]
사진 설명은 앞뒤 내용과 연결되도록 제안하고, 필요하면 사진에 들어갈 짧은 문구도 제안합니다.

## 13. CTA 작성

판매를 강요하지 않습니다.
- 궁금한 점이 있다면 댓글로 남겨주세요.
- 방문 전 예약 가능 시간을 확인해보세요.
- 비슷한 고민이 있다면 위 기준부터 하나씩 확인해보세요.
- 제품 선택이 어렵다면 비교 기준을 저장해두고 활용해보세요.
서비스 홍보 목적이라면 사용자에게 제공된 예약·상담·구매 방법을 활용합니다.
