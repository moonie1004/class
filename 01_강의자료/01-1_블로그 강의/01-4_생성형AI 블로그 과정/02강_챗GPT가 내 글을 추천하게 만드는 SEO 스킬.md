### 오늘의 한 줄

요즘은 검색창보다 챗GPT·퍼플렉시티에 물어보고 끝내는 사람이 많습니다. AI가 내 글을 물어다 주지 않으면 그 글은 없는 글이나 마찬가지예요. 무료 스킬 하나를 붙여 **내 사이트가 AI 추천에 잘 걸리는 구조인지** 진단하고, 고칠 순서를 받아옵니다.

### 오늘 끝나면 이걸 할 수 있습니다

- 명령 세 줄로 claude-seo 플러그인을 설치할 수 있다
- 내 사이트 주소 하나로 AI 검색 최적화 진단 리포트를 받을 수 있다
- 리포트에서 1~3순위만 골라 오늘 고칠 일로 바꿀 수 있다
- 글을 새로 쓸 때마다 점검하는 루틴(`/seo page`)을 만들 수 있다
- 설치가 막혔을 때 어디를 확인할지 안다
- SEO·AEO·GEO를 구분해서 설명하고, 'GEO 비법'이라며 도는 잘못된 방법을 걸러낼 수 있다

> 이 문서의 명령어와 요구사항은 2026년 9월 기준 공식 저장소·설치 문서에서 확인한 것입니다. 원문 대비 보강한 부분은 아래 [원문에서 보강한 내용](#원문에서-보강한-내용)에 정리했습니다.

## 왜 지금 이걸 하나

구글·네이버도 AI 요약 결과를 검색창 맨 위에 먼저 보여줍니다. 검색 결과 10개 중 하나로 들어가는 것보다, **AI가 답을 만들 때 인용되는 글**이 되는 게 중요해졌습니다.

![[260829-3897.png]]

claude-seo는 그 관점으로 사이트를 점검해 주는 무료 오픈소스 플러그인입니다. MIT 라이선스이고, 25개 하위 스킬과 18개 분석 에이전트가 병렬로 돌면서 기술 SEO·콘텐츠 품질(E-E-A-T)·스키마·AI 검색 최적화(GEO)·로컬/이커머스 SEO까지 봅니다.

## SEO가 맞나요, GEO가 맞나요?

강의에서 가장 많이 나오는 질문입니다. 결론부터 말하면 **둘 다 틀린 말은 아니지만, 2026년 기준으로는 "SEO 안에 GEO가 들어간다"가 맞습니다.**

### 세 용어부터 구분

| 용어 | 풀이름 | 목표 | 무대 |
| --- | --- | --- | --- |
| **SEO** | Search Engine Optimization | 검색 결과에서 상위에 노출 | 구글·네이버 검색 |
| **AEO** | Answer Engine Optimization | 답변 영역에 직접 인용 | 추천 스니펫, 음성 검색 |
| **GEO** | Generative Engine Optimization | AI가 답을 만들 때 근거로 인용 | 챗GPT·퍼플렉시티·AI 개요 |

### 구글의 공식 입장 (2026년 5월 15일)

구글이 AI 검색 최적화 가이드를 새로 내면서 이 논쟁을 정리했습니다.

> "구글 검색 관점에서, 생성형 AI 검색에 최적화하는 것은 곧 검색 경험에 최적화하는 것이며, 따라서 **여전히 SEO다**."
> — [구글 공식 AI 최적화 가이드](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide)

AI 개요(AI Overviews)와 AI 모드가 **기존 검색과 같은 랭킹 시스템 위에서 돌아가기 때문**입니다. 그래서 구글은 다음을 **하지 말라고 명시**했습니다. 요즘 'GEO 비법'이라며 도는 것 중 상당수가 여기 들어갑니다.

| 구글이 권하지 않는 것 | 이유 |
| --- | --- |
| `llms.txt` 파일, AI 전용 특수 마크업 | 구글이 읽지 않음 |
| 콘텐츠를 AI용으로 잘게 쪼개기(청킹) | 검색 시스템이 그렇게 보지 않음 |
| AI용으로 글을 따로 다시 쓰기 | 하나의 좋은 글이면 충분 |
| 언급 수를 늘리려는 가짜 멘션 | 신뢰도에 오히려 해로움 |
| AI 전용 구조화 데이터 | 기존 스키마로 충분 |

대신 구글이 강조한 것은 **남들이 안 쓴 내용(non-commodity content), 기본기(크롤링·색인·페이지 경험), 로컬·커머스 정보 정확성** 세 가지입니다.

### 그럼 GEO라는 말은 필요 없나?

아닙니다. 구분해서 알아두면 이렇게 정리됩니다.

- **구글·네이버 안의 AI(AI 개요, 네이버 AI 브리핑·AI탭)** → 기존 SEO와 같은 시스템. 따로 팔 게 아니라 SEO 기본기를 잘하면 됩니다.
- **밖에 있는 AI(챗GPT, 퍼플렉시티, 클로드)** → 검색 랭킹과 별개로 굴러가므로, 인용되기 쉬운 글 구조를 따로 신경 쓰는 게 여전히 유효합니다. 이 영역을 부르는 이름이 GEO입니다.

오늘 쓰는 claude-seo도 같은 관점입니다. 저장소 설명이 구글 입장을 그대로 따르고 있어서, 도구 이름은 `seo`이고 **AI 검색 최적화는 그 안의 한 항목(`/seo geo`)**으로 들어가 있습니다. 그래서 이 강의 제목도 'SEO 스킬'입니다.

> 💬 수강생에게는 이렇게 정리해 주세요. **"용어 싸움에 시간 쓰지 마세요. 할 일은 하나입니다 — 사람이 검색하는 말로 제목을 쓰고, 첫 문단에서 답을 주고, 근거를 붙이는 것. 그게 SEO이고 동시에 GEO입니다."**

## 1단계 · 설치 — 복붙 3줄

![[02-설치-3줄.png]]

Claude Code를 열고 아래 세 줄을 순서대로 붙여넣습니다.

```
/plugin marketplace add AgriciDaniel/claude-seo
/plugin install claude-seo@agricidaniel-claude-seo
/seo setup
```

| 줄 | 하는 일 |
| --- | --- |
| 1줄 | 이 플러그인이 있는 마켓플레이스를 등록 |
| 2줄 | 플러그인 설치 |
| 3줄 | **최초 1회만** — 분석에 필요한 파이썬 가상환경(`~/.claude/skills/seo/.venv/`)과 Chromium을 자동으로 준비 |

설치 확인은 Claude Code에서 `/seo`만 쳐보면 됩니다. 도움말이나 URL 입력 안내가 뜨면 정상입니다. 더 자세히 보려면 `/seo doctor`를 실행하세요.

### `/plugin`이 안 먹힐 때 — 수동 설치

Claude Code 버전을 올려도 안 되면 저장소를 직접 받아 설치합니다.

**Windows (PowerShell)**

```
git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git
powershell -ExecutionPolicy Bypass -File claude-seo\install.ps1
```

**Mac · Linux**

```
git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git
bash claude-seo/install.sh
```

## 2단계 · 내 사이트 링크 넣고 진단 받기

![[03-진단-리포트.png]]

설치가 끝났으면 한 줄이면 됩니다.

```
/seo audit https://내사이트주소
```

클로드가 사이트를 읽고 AI 검색이 좋아하는 구조인지 항목별로 점검한 뒤, 당장 고칠 것부터 **우선순위 리포트**로 정리해 줍니다. 페이지가 많은 사이트일수록 몇 분 걸릴 수 있습니다. 공식 명령어 문서에는 한 번에 최대 500페이지까지 크롤링하는 것으로 안내돼 있어요.

### 먼저 이것만 (처음 쓰는 6개)

| 하고 싶은 일 | 붙여넣을 명령 |
| --- | --- |
| 사이트 전체 진단 | `/seo audit [내 사이트 주소]` |
| 글 하나만 깊게 분석 | `/seo page [글 주소]` |
| AI 검색(챗GPT 추천) 최적화만 집중 점검 | `/seo geo [주소]` |
| 구조화 마크업(스키마) 점검·생성 | `/seo schema [주소]` |
| 사이트맵 만들기 | `/seo sitemap generate` |
| 설치 상태 점검 | `/seo doctor` |

#### `/seo geo`는 구체적으로 뭘 보나

'AI가 좋아하게'라는 막연한 말이 아니라, 인용되기 쉬운 글의 조건을 항목으로 점수 냅니다.

| 점검 항목 | 무엇을 보나 |
| --- | --- |
| 문단 인용 가능성 | 한 문단이 그 자체로 답이 되는 덩어리인지(대략 130~170단어 단위) |
| 질문형 제목 구조 | 소제목이 사람이 실제로 묻는 문장 형태인지 |
| 근거 밀도 | 수치·출처·인용이 본문에 얼마나 붙어 있는지 |
| 브랜드 언급 분포 | 위키백과·레딧·유튜브·링크드인 등 밖에서 언급되는지 |

> 마지막 항목은 '가짜 멘션을 만들라'는 뜻이 아닙니다. 구글이 명시적으로 말린 행동이에요. 실제로 쌓인 언급이 있는지 **현황을 보여주는 지표**로 읽으세요.

### 익숙해지면 쓸 것

| 하고 싶은 일 | 명령 |
| --- | --- |
| 기술적 문제만 점검 (크롤링·색인·속도·모바일) | `/seo technical [주소]` |

## 직접 써보고 느낀 꿀팁

**1. 리포트는 위에서부터 순서대로.** 고칠 것이 우선순위로 나옵니다. 전부 다 하려 하지 말고 1~3순위만 먼저 고치는 게 효율이 좋았습니다.

**2. 제목이 절반입니다.** 가장 크게 지적받은 게 제목(title, og:title)이었어요. `[AI 활용법]` 같은 단어 나열보다 **사람이 실제로 검색하는 단어**로 바꾸는 것부터 시작하세요.

**3. 첫 문단에서 질문에 답부터 하세요.** AI는 글 첫머리의 깔끔한 한 줄 정의를 그대로 인용해 가는 경우가 많습니다. 리포트에서도 반복해서 짚어 줍니다. 다만 **AI용으로 글을 따로 쪼개거나 다시 쓰라는 뜻은 아닙니다** — 구글이 말리는 방식이에요. 사람이 읽기에도 첫 문단에서 답이 나오는 게 좋은 글이라, 그 하나만 잘하면 됩니다.

**4. 결과를 한국어로 정리해 달라고 하세요.** 리포트가 영어로 나오면 이어서 이렇게 치면 됩니다 — "위 결과를 한국어로, 오늘 할 일 3개로 정리해줘".

**5. 고친 다음에 다시 돌려보세요.** 같은 명령을 한 번 더 돌리면 뭐가 나아졌는지 비교됩니다. 이게 제일 동기부여가 됩니다. (`/seo drift baseline` → 수정 → `/seo drift compare`로 자동 비교도 가능합니다.)

## 쓰기 전에 알아 두면 좋은 것

- 분석할 때 **내 사이트에 실제로 접속**해서 읽어옵니다. 내가 점검·수정할 권한이 있는 사이트에 써야 실제 개선으로 이어집니다.
- `/seo setup` 최초 실행은 파이썬 환경과 Chromium을 내려받느라 몇 분 걸릴 수 있습니다. Chromium 설치가 실패해도 기본 분석은 동작합니다.
- 스킬 자체는 무료(MIT 라이선스)지만, **Claude Code 사용량(플랜 한도)은 쓴 만큼 소모**됩니다.
- 리포트는 제안입니다. 브랜드 톤과 안 맞는 제안은 걸러서 적용하면 됩니다.
