### 오늘의 한 줄

블로그가 안 크는 이유는 글솜씨가 아니라 **"무엇을 쓸지 모르는 것"**입니다. 오늘은 **사람들이 실제로 검색하는 질문**을 한 시간 만에 수백 개 모으는 방법을 배웁니다. 질문 하나가 글 한 편입니다.

### 오늘 끝나면 이걸 할 수 있습니다

- 내 주제에서 서브주제 12개를 뽑을 수 있다
- 구글 '관련 질문' 섹션을 찾아 30개 이상의 질문을 캘 수 있다
- 모은 질문을 블로그 글감 목록으로 정리할 수 있다
- 질문을 그대로 제목으로 바꾸는 법을 안다
- 1년치 글감을 만드는 반복 구조를 갖는다

---

## 개요

### 이 방법의 원리

**사람들이 검색창에 치는 질문 = 이미 검증된 글감**입니다.

내가 상상해서 만든 주제는 아무도 안 찾을 수 있습니다. 하지만 구글이 "이런 것도 많이 물어봐요"라며 보여주는 질문은 **실제로 사람들이 검색한 것**입니다. 그걸 그대로 받아 적으면 됩니다.

### 전체 흐름 5단계


| 단계 | 할 일 | 결과 |
| --- | --- | --- |
| **1. 주제** | 내 콘텐츠 주제를 정한다 | 큰 주제 1개 |
| **2. 서브주제** | 관련 서브주제 12개를 쓴다 | 12개 |
| **3. 구글 검색** | 서브주제마다 '관련 질문'을 캔다 | 주제당 30개 이상 |
| **4. 만들기** | 질문 하나에 글 한 편(또는 영상 한 편) | 매일 1편 |
| **5. 반복** | 1년 동안 반복한다 | **365편 이상** |

> 📐 **계산해 보면** — 서브주제 12개 × 질문 30개 = **360개**. 여기에 하나만 더 캐면 1년치입니다. 이 작업 자체는 **한 시간이면 끝납니다.**

## PART 3. 3단계 — 구글 '관련 질문' 캐기 ⭐

**오늘의 핵심입니다.** 천천히 따라 해보세요.

### 3-1. '관련 질문'이 뭔가요

구글에서 뭔가를 검색하면, 결과 목록 **중간쯤에** 이런 상자가 나타납니다.

```
┌─────────────────────────────────┐
│  관련 질문                       │
├─────────────────────────────────┤
│  초등학생 집중력 몇 분인가요?      ⌄ │
│  아이 집중력 높이는 음식은?        ⌄ │
│  집중력 검사는 어디서 받나요?      ⌄ │
│  ADHD와 그냥 산만한 건 어떻게 구분? ⌄ │
└─────────────────────────────────┘
```

영어로는 **People Also Ask(PAA)**, 한국어 구글에서는 **"관련 질문"** 또는 **"다른 사람들이 묻는 질문"**으로 표시됩니다.

> 🎯 **이게 왜 금광인가** — 이 질문들은 구글이 만들어낸 게 아닙니다. **실제로 사람들이 검색한 질문**을 구글이 모아서 보여주는 겁니다. 즉, **검색량이 이미 검증된 글감**이에요.

### 3-2. 찾아가는 순서 ①~⑥

**① 구글을 엽니다**

주소창에 `google.com`을 칩니다. **네이버가 아니라 구글**입니다. 네이버에는 이 기능이 없어요.

> 💡 **시크릿 모드를 권합니다.** 크롬에서 `Ctrl + Shift + N`(맥은 `Cmd + Shift + N`). 내 검색 기록이 결과에 영향을 주지 않아서 **더 일반적인 질문**이 나옵니다.

**② 서브주제 하나를 검색합니다**

12개 중 하나를 골라 그대로 칩니다. 예: `초등학생 집중력`

**③ 결과 화면을 아래로 내립니다** ⭐

여기가 사람들이 가장 많이 막히는 부분입니다.

- '관련 질문' 상자는 **맨 위에 없습니다.** 보통 검색 결과 **3~5번째 사이**에 끼어 있습니다
- 광고가 위에 여러 개 붙어 있으면 더 아래에 있습니다
- **한 화면 반에서 두 화면 정도** 스크롤하면 나옵니다
- 마우스 휠로 천천히 내리면서 **"관련 질문"이라는 회색 글자**를 찾으세요

> ❗ **안 보인다면** — 모든 검색어에 나오는 건 아닙니다. **PART 3-4의 해결법**을 보세요.

**④ 질문 하나를 클릭해서 펼칩니다**

질문 오른쪽 끝의 **`⌄`(아래 화살표)**를 누르거나, 질문 글자를 그냥 클릭합니다. 그러면 아래로 펼쳐지면서 **짧은 답변 미리보기와 출처 사이트 링크**가 나옵니다.

**⑤ 여기가 진짜 기술입니다 — 계속 펼치기** ⭐⭐

> **질문 하나를 펼칠 때마다, 목록 맨 아래에 새 질문이 자동으로 추가됩니다.**

처음에는 질문이 3~4개뿐이지만, 하나 펼치면 5개, 또 하나 펼치면 6개… 이렇게 **계속 늘어납니다.**

**그래서 이렇게 합니다.**

1. 맨 위 질문을 펼친다
2. 두 번째 질문을 펼친다
3. 세 번째… 이렇게 **위에서부터 순서대로 계속** 펼친다
4. 아래로 내려가면서 **새로 생긴 질문도 계속** 펼친다
5. 30개가 넘을 때까지 반복한다

> 📌 원문 카드의 빨간 화살표가 가리키는 게 바로 이 동작입니다. **"위아래로 클릭하면 30개의 질문이 나오게 됩니다."**

**⑥ 질문만 복사해서 적어둡니다**

답변은 필요 없습니다. **질문 문장만** 노션·엑셀·메모장에 옮겨 적으세요.

> ⚠️ **답변 본문을 복사해 오지 마세요.** 그건 남의 글입니다. 우리가 가져오는 건 **질문(=주제)**이지 답이 아닙니다. 답은 내 경험과 내 조사로 씁니다.

### 3-3. 반복해서 1년치 만들기

서브주제 12개에 대해 ②~⑥을 반복합니다.

```
서브주제 1개 → 질문 30개
서브주제 12개 → 질문 360개 이상
```

> **이 과정을 다른 주제들에도 반복하면 365개 이상의 질문이 쌓입니다.**

### 3-4. '관련 질문'이 안 보일 때

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 상자가 아예 없다 | 검색어가 너무 짧거나 상품성 검색어 | **질문형으로** 바꿔보기 → "초등학생 집중력" ❌ → "초등학생 집중력 높이는 법" ⭕ |
| 여전히 없다 | 그 검색어에는 원래 안 나옴 | 서브주제를 조금 바꿔 다시 검색 |
| 질문이 몇 개뿐이다 | 아직 안 펼침 | **하나씩 펼치면 계속 늘어납니다** (3-2 ⑤단계) |
| 영어 질문이 나온다 | 지역·언어 설정 | 구글 하단 설정에서 지역을 한국으로 |
| 내 관심사 위주로만 나온다 | 검색 기록 개인화 | **시크릿 모드**로 다시 검색 |

### 3-5. 질문을 더 캐는 보조 창구 4가지

'관련 질문'만으로 부족하면 여기서도 캡니다. **전부 "사람들이 실제로 친 말"**이라는 공통점이 있습니다.

| 창구 | 어디서 | 어떻게 |
| --- | --- | --- |
| **구글 자동완성** | 구글 검색창 | 검색어를 치고 **엔터를 누르지 말고** 뜨는 목록을 봅니다 |
| **구글 관련 검색어** | 검색 결과 **맨 아래** | 페이지 끝까지 내리면 관련 검색어 묶음이 있습니다 |
| **네이버 자동완성** | 네이버 검색창 | 국내 검색어라 우리 블로그에 더 잘 맞습니다 |
| **네이버 지식iN** | 지식iN에서 주제 검색 | **질문 그 자체**가 모여 있는 곳입니다 |

> 💡 **조합 팁** — 검색어 뒤에 `방법`, `비용`, `추천`, `후기`, `차이`, `초보`를 하나씩 붙여 자동완성을 보면 질문이 훨씬 많이 나옵니다.

## PART 4. 4단계 — 질문을 글로 바꾸기

원문 카드는 이 단계에서 **60초 영상**을 찍으라고 안내합니다. 우리는 **블로그 글**로 바꿉니다. 원리는 같습니다.

### 4-1. 질문 = 제목

캔 질문을 **거의 그대로 제목으로** 쓰면 됩니다. 사람들이 검색한 말 그대로이기 때문에 검색에 걸리기 좋습니다.

| 캔 질문 | 블로그 제목 |
| --- | --- |
| 초등학생 집중력 몇 분인가요? | 초등학생 집중력, 학년별로 몇 분이 정상일까요? |
| 아이 집중력 높이는 음식은? | 아이 집중력에 좋다는 음식 5가지, 직접 먹여본 후기 |
| 집중력 검사는 어디서 받나요? | 초등 집중력 검사, 어디서 얼마에 받을 수 있나 |

> 🔗 제목을 더 끌리게 만드는 방법은 [[01-6_후킹 제목과 카드뉴스 표지 공식]]을 함께 보세요.

### 4-2. 글의 기본 뼈대

질문형 글감은 구조가 단순합니다.

```
① 질문을 다시 던진다 (독자의 상황에 공감)
② 첫 문단에서 바로 답한다      ← 가장 중요
③ 왜 그런지 설명한다
④ 내 경험·사례를 붙인다
⑤ 다음 행동을 안내한다
```

> ⭐ **②번이 핵심입니다.** 답을 맨 아래에 숨겨두면 독자가 나갑니다. 검색해서 들어온 사람은 **답을 확인하러 온 것**입니다.

### 4-3. 하루 한 편, 매일

| 원문(영상) | 블로그로 바꾸면 |
| --- | --- |
| 질문 하나 고르기 | 질문 하나 고르기 |
| 60초 안에 답하는 영상 촬영 | **한 질문에 한 편**, 짧아도 됨 |
| 캡컷으로 편집 | 사진 3~5장 넣고 문단 나누기 |
| 업로드 | 발행 |

## PART 5. 5단계 — 반복

> **가장 중요한 건 반복입니다. 1년 동안 매일 이 과정을 반복하면 여러분의 계정은 반드시 성장합니다.**

### 왜 반복이 효과가 있나

| 이유 | 설명 |
| --- | --- |
| 검색 유입이 **쌓입니다** | 어제 쓴 글이 1년 뒤에도 사람을 데려옵니다 |
| 한 주제가 **깊어집니다** | 같은 분야 글이 쌓이면 그 분야 블로그로 인정받습니다 |
| **소재 걱정이 사라집니다** | 이미 360개가 목록에 있으니까요 |
| 실력이 **자동으로 늡니다** | 100편 쓴 사람의 101번째 글은 첫 글과 다릅니다 |

### 지치지 않게 하는 3가지

1. **완벽하게 쓰려 하지 마세요.** 질문 하나에 답 하나면 충분합니다.
2. **목록에서 순서대로** 고르세요. 매번 "뭘 쓸까" 고민하면 그것만으로 지칩니다.
3. **주 3회로 줄여도 됩니다.** 매일보다 **끊기지 않는 것**이 중요합니다.

## ⚠️ 주의할 점

**1. 질문만 가져오고, 답은 내가 씁니다.** 관련 질문 상자에 뜨는 답변 미리보기는 다른 사람의 글입니다. 복사해서 쓰면 유사문서가 됩니다.

**2. 검색된다고 다 쓸 필요는 없습니다.** 내가 답할 수 있는 질문만 고르세요. 모르는 걸 아는 척하면 금방 들킵니다.

**3. 질문을 제목에 그대로 쓰되, 답도 제목값을 해야 합니다.** "집중력 높이는 법"이라고 써놓고 정작 방법이 없으면 다음부터 아무도 안 옵니다.
