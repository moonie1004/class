## PART 1. 적합도 — AI가 우리 매장을 무엇으로 아는가

플레이스 순위는 키워드를 넣는다고 오르지 않습니다. **기본 검색 로직(C-Rank + D.I.A.)에 더해, AI가 우리 매장을 어떤 '개체'로 인식했는지**가 함께 작용합니다.

> 🧩 **개체(Entity)란?** — "이 가게는 **○○ 하는 곳**"이라는 확정된 정체성입니다. AI가 '미용실'인지 '속눈썹 전문샵'인지 헷갈리면 어느 검색에도 제대로 안 걸립니다.

### 1-1. 영역별로 봇이 학습하는 것

| 영역 | 봇이 여기서 배우는 것 |
| --- | --- |
| **상호명 / 대표 카테고리** | 매장의 본질. **최상위 개체** (예: 미용실, 속눈썹) |
| **대표키워드 5개** | 매장이 **직접 선언하는 주력 타깃** (메인 상권 + 대표 시술·메뉴) |
| **상세 소개글** | 문맥. 시술 특징, 타깃 고객, 전문성 |
| **메뉴·가격 명칭과 설명** | 실제 거래가 일어나는 제품. **구체적 세부 니즈(롱테일)와 직결** |
| **찾아오시는 길** | 지리적 세부 위치(랜드마크·상가명·인근 역)와 접근성 |

> 🔗 대표키워드 5칸은 [[05강_대표키워드 5슬롯 채우기]], 순서 배치는 [[05-1강_대표키워드 5칸 중요도 순 배치]]에서 다뤘습니다.

### 1-2. '만점 기준'은 지역·업종마다 다릅니다 ⭐

**네이버는 전국 매장에 똑같은 절대 기준을 적용하지 않는 것으로 분석됩니다.** 같은 행정동 + 같은 업종의 상위권 매장들이 만들어 놓은 평균이 그 카테고리의 **기준점**이 됩니다.

| 우리 동네 유형 | 무엇이 만점을 가르나 | 그래서 할 일 |
| --- | --- | --- |
| **경쟁 밀집 상권** (강남권 뷰티·외식 등) | 리뷰 수, 예약 전환, 저장 수, 체류시간의 **기준선이 매우 높음** → 사용자 반응 지표 비중 큼 | 리뷰·저장·예약을 늘리는 데 집중 |
| **로컬 주거·배후 상권** (동네 상권) | 외부 유입이 적어 반응 지표가 적음 → **기본 세팅 완성도**에 가중치 | 스마트콜·예약·톡톡 연동, 메뉴 사진·설명, 키워드 적합도를 100% 채우기 |

> 🎯 **이게 왜 중요한가** — 동네 매장이 강남 매장 흉내를 낼 필요가 없습니다. **우리 동네 상위권이 하고 있는 것**이 기준입니다. 그리고 동네 상권일수록 **빈칸 없이 다 채우는 것만으로** 상위권에 갈 수 있습니다.

#### ✏️ 우리 동네 기준점 파악하기

같은 동 + 같은 업종 상위 3곳을 열어서 채워보세요.

| 항목 | 1위 | 2위 | 3위 | 우리 |
| --- | --- | --- | --- | --- |
| 리뷰 수 | | | | |
| 사진 수 | | | | |
| 메뉴에 설명이 있나 | | | | |
| 예약 연동 | | | | |
| 톡톡·스마트콜 | | | | |
| 소식 최근 등록일 | | | | |

> 빈칸이 우리만 있는 항목 = **가장 먼저 채울 것**

### 1-3. 키워드 스터핑은 감점, 연관어는 가점

**❌ 같은 단어 도배**

```
속눈썹펌 속눈썹펌 속눈썹펌 속눈썹펌 속눈썹펌
```

한 영역에 같은 단어를 억지로 반복하면 **스팸 필터에 걸려 감점**됩니다.

**⭕ 연관어로 넓히기**

메인 키워드가 `속눈썹펌`이라면, 같은 말을 반복하는 대신 **의미가 연결된 단어들**을 자연스럽게 분산시킵니다.

| 메인 | 함께 쓸 연관어 |
| --- | --- |
| 속눈썹펌 | C컬 · 노글루 · 유지력 · 영양 · 자연스러운 · 눈매 · 손상 없는 |

> 💡 **왜 효과가 있나** — 검색 시스템은 단어를 하나씩 따로 보지 않고 **의미가 묶인 단어 무리**로 이해합니다. 연관어가 함께 있으면 "이 집은 진짜 속눈썹 전문이구나"로 읽힙니다.

## PART 2. 구조화 — AI가 읽기 쉽게 쓰기

구조화란 **AI가 텍스트를 읽을 때 "무엇을, 누구에게, 어디서"를 헤매지 않고 단락별로 확정할 수 있게** 규격을 맞추는 작업입니다.

### 2-1. 소개글 — 두괄식 3단락 공식 ⭐

**AI는 문단의 첫 문장을 가장 중요한 정의문으로 읽습니다.** 그래서 결론을 앞에 둡니다.

```
[1단락 — 핵심 정체성 정의]
○○동 ○○프라자에 위치한 속눈썹 전문 샵입니다.

[2단락 — 차별점 3가지, 기호로 나열]
• 1:1 맞춤 눈매 디자인 및 손상 없는 노글루 시술
• 100% 정품 인증 재료 사용 및 철저한 위생 관리
• 첫 방문 고객 맞춤 상담 및 애프터케어 키트 증정

[3단락 — 타깃 고객과 방문 안내]
인근 주거민과 직장인을 위한 당일 예약 가능, 무료 주차 안내.
```

| 단락 | 역할 | 반드시 들어갈 것 |
| --- | --- | --- |
| 1 | **정체성 확정** | 지역명 + 상가명 + 전문 분야 |
| 2 | **차별점** | 기호(•)로 3가지. 각 줄에 연관어 |
| 3 | **타깃·안내** | 누구를 위한 곳인지 + 예약·주차 |

| --- | --- |
| 1 | |
| 2-① | |
| 2-② | |
| 2-③ | |
| 3 | |

### 2-2. 메뉴 — 이름 + 설명을 문장으로

```
❌  속눈썹펌 / 40,000원
```

이렇게 적으면 AI는 **가격표로만** 인식합니다. 아무 검색에도 안 잡힙니다.

```
⭕  메뉴명: [시그니처] 수분 케라틴 노글루 속눈썹펌
    설명: 손상모를 보호하는 수분 영양 케어로 꺾임 없이 부드러운
          C컬·JC컬을 연출하는 1:1 맞춤 펌 (소요 50분, 유지 4~6주)
```

> 🎯 이렇게 써야 **'노글루펌', '수분펌', 'C컬'** 검색에 이 메뉴가 답으로 매칭됩니다.

**메뉴 설명에 꼭 넣을 5요소**

| 요소 | 예 |
| --- | --- |
| 무엇을 쓰나 | 수분 케라틴, 정품 재료 |
| 어떤 효과 | 손상 보호, 꺾임 없음 |
| 어떤 종류 | C컬 · JC컬 |
| 소요 시간 | 50분 |
| 유지 기간 | 4~6주 |

> 🔗 메뉴 이름 짓기는 [[09강_메뉴 이름과 가격 설계]]와 함께 보세요.

### 2-3. 찾아오시는 길 — 지리 정보를 순서대로

```
[주요 랜드마크] → [상가·건물명] → [층수와 층별 위치] → [주차 정보]
```

**예시**

> ○○동 ○○프라자 3층에 위치해 있으며, 1층 △△약국 옆 엘리베이터를 이용하시면 편리합니다. 건물 지하 전용 주차장 무료 이용 가능합니다.

> 🔗 [[13강_소개글 5단계와 찾아오는 길]]의 작성법과 함께 적용하세요.

### 2-4. ⭐ 키워드 나열을 문장으로 바꾸기

이 파트에서 가장 중요한 기술입니다.

```
❌  우면동속눈썹펌 양재속눈썹 속눈썹연장
    (단순 나열 — AI가 관계를 모름)
```

```
⭕  우면동 우면프라자에서 손상 없는 속눈썹펌과 속눈썹연장을
    전문으로 진행하며, 양재 및 서초 인근에서도 편하게 찾아오실 수 있습니다.
    (서술형 — 지역·시술·접근성의 관계가 확정됨)
```

같은 단어가 들어 있어도, **관계가 문장으로 연결되면** AI가 훨씬 정확히 이해합니다.

## PART 3. 일관성 — 밖에서도 같은 말을 하는가

검색 엔진은 플레이스 안만 보지 않습니다. **블로그·인스타그램·지도·영수증 리뷰까지 훑어서 교차 검증**합니다.

### 3-1. 일관성이 점수를 올리는 흐름

```
[외부 블로그 · SNS · 지도] ──(키워드·정보 일치)──▶ [스마트플레이스]
                                  │
                                  ▼
                    [AI 브리핑 · 스마트블록에 인용]
                    "여러 곳에서 확인되니 믿을 만한 답"
                                  │
                                  ▼
                    [플레이스 지수 · 순위 상승]
```

같은 키워드군이 **여러 출처에서 반복 확인될수록** AI는 그것을 검증된 사실로 확정합니다. 그리고 **AI 브리핑에 인용되는 것 자체가 신뢰도 인증**이라, 순위까지 함께 올라가는 선순환이 생깁니다.

### 3-2. 4가지 통일 전략

#### ① 타깃을 하나로 좁힌다

여러 사람을 다 잡으려 하면 AI도 누구를 위한 곳인지 모릅니다.

> 예: "○○동 인근 주거민과 △△ 직장인을 위한 자연스러운 1:1 맞춤 뷰티케어"

#### ② NAPW를 100% 똑같이 맞춘다 ⭐

**N**ame(상호명) · **A**ddress(주소) · **P**hone(전화) · **W**ebsite(링크)를 **띄어쓰기 하나까지** 동일하게 맞춥니다.

| 채널 | 확인 | ⬜ |
| --- | --- | --- |
| 스마트플레이스 | 기준 | ⬜ |
| 인스타그램 프로필 | 위와 동일한가 | ⬜ |
| 당근 비즈프로필 | 동일한가 | ⬜ |
| 카카오맵 | 동일한가 | ⬜ |
| 블로그 프로필·하단 | 동일한가 | ⬜ |

> ⚠️ **흔한 사고** — 플레이스는 '○○뷰티', 인스타는 '○○ 뷰티샵', 카카오맵은 옛 주소. 이렇게 갈리면 AI가 **같은 가게인지 확신하지 못합니다.**

#### ③ 외부 글에도 같은 키워드를 쓴다

체험단이나 자체 블로그 글을 쓸 때, **플레이스 대표키워드 5개와 같은 조합**을 제목과 소제목에 씁니다.

> 예: 플레이스에 `우면동속눈썹`, `우면동속눈썹펌`이 있다면 블로그 제목에도 그대로.

#### ④ 리뷰와 답글에 키워드를 심는다

**리뷰 유도** — "친절해요" 대신 구체적인 말이 나오도록 미션을 설계합니다.

| ❌ 밋밋한 리뷰 | ⭕ 키워드가 담긴 리뷰 |
| --- | --- |
| 친절해요 | ○○동에서 속눈썹펌 제일 잘해요 |
| 좋아요 | ○○프라자라 주차가 편해요 |

**사장님 답글** — 단답형 대신 타깃 키워드를 자연스럽게 넣습니다.

> "방문해 주셔서 감사합니다! 저희 ○○동 ○○프라자 매장의 시그니처인 **수분 케라틴 속눈썹펌**의 자연스러운 컬감이 고객님 눈매와 잘 어울려 뿌듯합니다. 다음에도 꼼꼼한 관리로 보답하겠습니다."

> ⚠️ **주의** — 리뷰 문구를 대가와 바꾸거나 특정 문장을 강요하면 안 됩니다. 자연스럽게 **무엇이 좋았는지 구체적으로 써 달라고 요청**하는 선까지입니다. 대가를 제공한 리뷰라면 표시가 필요합니다.

> 🔗 리뷰·답글 전략은 [[18강_별점 관리와 리뷰·답글 전략]]에서 자세히 다룹니다.

## 검증 상태 — 어디까지가 확인된 사실인가

| 내용 | 상태 |
| --- | --- |
| C-Rank(출처)와 D.I.A.(문서)가 랭킹에 작용한다 | ⭕ 네이버 공식 |
| 리뷰·저장·예약·체류시간 등 이용자 반응이 순위에 영향 | ⭕ 널리 확인됨 |
| 메뉴 설명·소개글·찾아오는 길이 검색에 쓰인다 | ⭕ 널리 확인됨 |
| 같은 단어 반복(스터핑)이 불리하다 | ⭕ 널리 확인됨 |

| **지역·업종별 상대평가 '만점 기준'** | ⚠️ 업계 분석. 공식 발표 아님 |
