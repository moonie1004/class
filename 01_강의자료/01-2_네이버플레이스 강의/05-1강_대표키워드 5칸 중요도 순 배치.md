### 오늘의 한 줄

대표키워드 5개를 **무엇으로 채울지**는 [[05강_대표키워드 5슬롯 채우기]]에서 정했습니다. 오늘은 그 5개를 **어떤 순서로 놓을지**를 정합니다. 같은 키워드라도 순서가 다르면 결과가 달라집니다.

### 오늘 끝나면 이걸 할 수 있습니다

- 키워드 순서가 왜 중요한지 3가지 이유로 설명할 수 있습니다
- 1번~5번 칸에 각각 어떤 성격의 키워드가 들어가야 하는지 압니다
- 우리 매장 5칸을 황금 배치 공식대로 확정할 수 있습니다
- 순서를 잘못 잡았을 때 생기는 3가지 실수를 피할 수 있습니다
- 대표키워드와 소개글·메뉴를 일치시켜야 하는 이유를 압니다

> 📌 **먼저 알아두세요** — "대표키워드를 중요도 순으로 배치해야 한다"는 것은 **실무 마케팅 현장에 널리 퍼진 정설**이며, 네이버의 검색 인덱싱 방식과 사용자 경험 관점에서 타당한 분석입니다. 다만 **네이버가 공식 문서로 발표한 규칙은 아닙니다.** 자세한 구분은 [맨 아래 검증 상태 표](#검증-상태--어디까지가-확인된-사실인가)를 참고하세요.

## PART 1. 키워드 순서가 중요한 3가지 이유

### ① 앞자리일수록 '우리 매장의 정체성'으로 읽힙니다

검색엔진은 목록 형태의 데이터를 읽을 때 기본적으로 **앞에서 뒤로** 읽습니다. 1~5번 중 **앞자리에 있는 단어일수록 "이 매장은 이런 곳이다"를 규정하는 핵심 정보로 더 큰 비중을 받을 가능성이 높습니다.**

> 🏷️ **비유** — 명함을 건넬 때 이름 아래 첫 줄에 뭘 쓰느냐와 같습니다. 첫 줄이 "파스타 전문점"인 것과 "주차 가능"인 것은 상대가 기억하는 게 완전히 달라집니다.

### ② 화면에 앞의 1~2개만 보입니다

모바일 검색이나 지도에서 매장 목록이 뜰 때, **대표키워드 5개가 전부 보이지 않습니다.** 앞의 1~2개만 나오거나 말줄임표(…)로 잘리는 경우가 많습니다.

| 무슨 뜻인가 | 그래서 |
| --- | --- |
| 손님 눈에 닿는 건 **앞자리 키워드** | 가장 많이 검색되는 핵심 키워드를 앞에 |
| 눈길을 끌면 **클릭률(CTR)이 올라감** | 클릭률 상승은 순위 상승으로 이어짐 |

> 🎯 이건 알고리즘 이전에 **사람의 눈** 문제입니다. 안 보이는 자리에 좋은 키워드를 넣어봐야 소용이 없습니다.

### ③ 스마트블록·AI 요약에 묶이기 쉬워집니다

요즘 네이버 검색은 상호명 매칭을 넘어 **'지역 + 상황/목적'** 기반의 스마트블록을 보여줍니다. (예: "강남역 데이트하기 좋은 곳", "회식하기 좋은 강남 맛집")

**앞쪽에 업종의 본질과 대표 타깃이 분명히 적혀 있어야**, AI가 우리 매장을 어느 카테고리로 묶을지 판단하기 쉬워집니다. 앞자리가 애매하면 어느 블록에도 못 들어갑니다.

> 🔗 AI가 매장 정보를 읽어가는 흐름은 [[03강_매장 컨셉 한 줄 만들기]]와 [[05강_대표키워드 5슬롯 채우기]]의 PART 5(봇이 1차로 읽는 자리)와 이어집니다.

## PART 2. 대표키워드 5칸 황금 배치 공식 ⭐

무작위로 적지 말고, **핵심 → 세부**로 가중치를 점점 분산시키는 구조로 놓습니다.

### 2-1. 칸별 역할

| 순서 | 키워드 성격 | 목적 |
| --- | --- | --- |
| **1번 (최우선)** | 핵심 메인 키워드 | 매장의 본질이자 **유입량이 가장 큰** 키워드 |
| **2번 (주력)** | 대표 메뉴·서비스 | 우리 매장의 **1등 시그니처** |
| **3번 (세부 상권)** | 인접 랜드마크·세부 위치 | 1번 상권보다 **더 구체적인** 위치 |
| **4번 (목적·상황)** | 소비자 방문 의도 | 손님이 **왜 오는가** (D.I.A. 관점) |
| **5번 (특징·형태)** | 분위기·편의·모임 형태 | 룸, 콜키지, 회식 같은 **롱테일 보완** |

### 2-2. 업종별 배치 예시

**① 강남 파스타 매장**

| 칸 | 예시 |
| --- | --- |
| 1 | 강남역맛집 / 강남역파스타 |
| 2 | 강남스테이크 / 화덕피자 |
| 3 | 신논현역맛집 / 역삼동파스타 |
| 4 | 강남역데이트 / 강남소개팅 |
| 5 | 강남룸식당 / 강남와인바 |

**② 동네 미용실** (적용 연습용)

| 칸 | 성격 | 예시 |
| --- | --- | --- |
| 1 | 핵심 메인 | 곡반정동미용실 |
| 2 | 대표 시술 | 레이어드컷 / 히피펌 |
| 3 | 세부 위치 | 라퍼스트미용실 (상가 이름) |
| 4 | 방문 목적 | 남자머리잘하는곳 / 웨딩헤어 |
| 5 | 특징 | 1인샵 / 주차가능미용실 |

**③ 동네 정형외과** (적용 연습용)

| 칸 | 성격 | 예시 |
| --- | --- | --- |
| 1 | 핵심 메인 | 해운대정형외과 |
| 2 | 대표 진료 | 도수치료 / 체외충격파 |
| 3 | 세부 위치 | 좌동정형외과 |
| 4 | 방문 목적 | 어깨통증 / 교통사고치료 |
| 5 | 특징 | 야간진료 / 토요일진료 |

## PART 3. 흔한 실수 3가지

### 실수 ① 업종과 무관한 '조회수 높은 키워드' 욕심

파스타집인데 조회수가 높다는 이유로 1번에 `강남역카페`나 `강남역고기집`을 넣는 경우입니다.

| 무슨 일이 생기나 |
| --- |
| 네이버가 분류한 우리 매장의 **업종 카테고리와 불일치** |
| 검색해서 들어온 손님이 **원하던 곳이 아님** → 클릭·체류 저조 |
| 결과적으로 **감점** |

> ❌ 띄우고 싶은 키워드 / ⭕ 실제로 파는 것

### 실수 ② 지역명을 5칸 전부에 중복

```
❌  강남역맛집 · 강남역파스타 · 강남역데이트 · 강남역피자 · 강남역스테이크
```

다섯 칸을 썼는데 잡히는 검색은 사실상 '강남역' 하나입니다.

```
⭕  강남역맛집 · 화덕피자 · 신논현역맛집 · 강남소개팅 · 강남와인바
```

**상권 + 메뉴 + 목적 + 특징을 다양하게 조합**해야 노출 범위가 넓어집니다.

> 💡 **점검법** — 5칸을 소리 내어 읽어보세요. 같은 단어가 3번 이상 반복되면 다시 짜세요.

### 실수 ③ 소개글·메뉴와 따로 노는 키워드

**대표키워드에 적은 단어는 매장 정보 곳곳에도 자연스럽게 들어 있어야 합니다.**

| 확인할 곳 | 점검 | ⬜ |
| --- | --- | --- |
| 소개글 | 5개 키워드가 문장 속에 자연스럽게 있나 | ⬜ |
| 대표 메뉴 이름·설명 | 2번 칸 키워드가 실제 메뉴에 있나 | ⬜ |
| 네이버 예약 옵션 | 서비스명이 키워드와 맞나 | ⬜ |
| 찾아오는 길 | 3번 칸의 세부 상권·랜드마크가 언급되나 | ⬜ |

> 🔑 대표키워드만 있고 본문에 없으면, 봇 입장에서는 **"말은 이렇게 해놓고 근거가 없네"**가 됩니다. 반대로 여기저기서 같은 이야기가 나오면 신뢰도가 올라갑니다.

> 🔗 소개글 작성은 [[13강_소개글 5단계와 찾아오는 길]], 메뉴 이름은 [[09강_메뉴 이름과 가격 설계]]와 함께 맞추세요.

## 검증 상태 — 어디까지가 확인된 사실인가

이 강의 내용은 **실무 현장의 정설과 합리적 분석**을 정리한 것입니다. 수강생에게 전달할 때 구분해 주세요.

| 내용 | 상태 |
| --- | --- |
| 대표키워드가 검색·노출에 쓰이는 정보라는 점 | ⭕ 널리 확인됨 |
| 클릭률·체류시간 등 이용자 반응이 순위에 영향을 준다는 점 | ⭕ 널리 확인됨 |
| 모바일 화면에서 키워드가 잘려 보인다는 점 | ⭕ 화면에서 직접 확인 가능 |
| 업종 카테고리와 맞지 않는 키워드가 불리하다는 점 | ⭕ 널리 확인됨 |
| 대표키워드와 본문 정보가 일치해야 유리하다는 점 | ⭕ 널리 확인됨 |
| **"앞자리 키워드에 더 큰 가중치가 붙는다"** | ⚠️ **합리적 추론.** 네이버가 공식 발표한 규칙은 아님 |
| **1~5번 칸의 성격 배치 공식** | ⚠️ **실무 권장안.** 공식 가이드 아님 |

> 💬 **그래도 이대로 하시면 됩니다.** ⚠️ 항목이 공식이 아니어도 **손해 볼 것이 없습니다.** 중요한 것을 앞에 놓고, 같은 단어를 반복하지 않고, 실제로 파는 것만 적는 건 어떤 알고리즘에서든 나쁠 이유가 없습니다. 게다가 ②번(화면에 앞의 1~2개만 보임)은 알고리즘과 무관하게 **사람 눈에 걸리는 문제**라 그 자체로 충분한 이유가 됩니다.
