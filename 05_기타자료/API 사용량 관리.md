## Brave Search API 사용량 확인

- [ ] Brave Search API 사이트([api.search.brave.com/app/dashboard](https://api.search.brave.com/app/dashboard))의 Home(홈 화면)으로 들어간다.
- [ ] 화면 하단의 `Usage analytics` (사용량 분석) 영역을 확인한다.
  - Time range: `This month` (이번 달)로 설정
  - Metric: `Successful Requests` (성공한 요청 수)로 설정
- [ ] 그래프와 숫자(예: `150 / 1,000`)로 이번 달에 클로드가 검색을 총 몇 번 썼는지 확인한다.

### 1,000건 초과 방지 팁 (과금 안 되게 막기)

- [ ] 대시보드의 `Settings` 또는 `Billing` 메뉴에서 월 사용 한도(Spending Limit)를 **$0 또는 $5**로 고정해 둔다.
  - 한도를 걸어두면 1,000건을 넘겨도 추가 결제되지 않고, 검색 기능만 다음 달 1일까지 일시 정지되므로 과금 걱정 없이 사용할 수 있다.
