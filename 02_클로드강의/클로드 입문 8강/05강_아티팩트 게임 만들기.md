### 오늘의 한 줄

클로드에게 무언가를 만들어 달라고 하면 알 수 없는 글자(코드)만 잔뜩 나와서 당황한 적 있으신가요? 사실 그 코드는 **실제로 움직이는 모습으로 바로 볼 수 있습니다.** 오늘은 그 창인 「아티팩트」를 열어서, 진짜로 플레이되는 게임 하나를 직접 만들어 봅니다.

### 오늘 끝나면 이걸 할 수 있습니다

- 아티팩트가 무엇인지 한 문장으로 설명할 수 있습니다
- 왼쪽 메뉴에서 아티팩트를 찾아 「새 아티팩트 만들기」를 누를 수 있습니다
- 클로드와 대화하며 나만의 게임을 하나 만들어서 직접 플레이할 수 있습니다
- 「미리보기」와 「코드」 탭을 오가며 결과물을 확인할 수 있습니다
- 만든 아티팩트를 채팅으로 이어서 고칠 수 있습니다
- 아티팩트로 만들면 좋은 것 5가지를 예로 들 수 있습니다

## PART 1. 아티팩트가 뭔가요

### 한 줄 정의

**아티팩트 = 클로드가 만든 것을 "실제로 작동하는 모습"으로 보여 주는 창입니다.**

[[04강_프로젝트 블로그 글쓰기 시연]]에서 블로그 글을 받아 봤죠. 그때 결과물을 클릭하면 답변 옆에 문서 형태로 따로 열리는 창이 있었습니다. **그게 바로 아티팩트입니다.**

### 비유로 이해하기

요리에 비유하면 이렇습니다.

- **채팅 답변** = 요리 레시피를 글로 적어 준 것
- **아티팩트** = 그 레시피대로 실제로 완성된 요리를 접시에 담아 내온 것

클로드에게 무언가를 시키면 보통 코드 작성 같은 걸 해 줍니다. 그런데 코드만 봐서는 뭐가 뭔지 알 수 없죠. 아티팩트는 **그 코드를 실제로 구현한 모습**을 눈으로 볼 수 있게 해 주는 도구입니다.

### 아티팩트는 언제 유용한가요

답변이 길거나, 눈으로 봐야 이해되는 것일 때 자동으로 나오는 경우가 많습니다.

| 이럴 때 | 아티팩트로 나오면 좋은 이유 |
| --- | --- |
| 긴 글을 받았을 때 | 채팅창이 스크롤로 밀리지 않고, 옆 창에서 차분히 읽을 수 있습니다 |
| 표로 정리해 달라고 했을 때 | 표 모양이 깔끔하게 유지됩니다 |
| 계산기 같은 걸 만들 때 | 숫자를 직접 눌러 보며 작동을 확인할 수 있습니다 |
| 간단한 게임을 만들 때 | 바로 플레이해 볼 수 있습니다 |
| 웹페이지를 만들 때 | 완성된 화면이 어떻게 보이는지 미리 확인할 수 있습니다 |

> 참고: [[02강_모델 선택과 기본 설정 세팅]]에서 설정의 **시각자료 → 아티팩트 / AI 기반 아티팩트**를 켜 두라고 했습니다. 아직 안 켰다면 지금 켜고 오세요.

## PART 2. 화면 따라하기 — 아티팩트 메뉴 열기

① 왼쪽 위의 **「사이드바 열기」**를 눌러 왼쪽 메뉴를 펼칩니다

② 메뉴에서 **「아티팩트」**를 클릭합니다

③ **「새 아티팩트 만들기」**를 클릭합니다

④ 무엇을 만들 수 있는지 종류가 나옵니다

- 앱
- 웹사이트
- 문서
- 템플릿
- 게임
- 그 외 여러 가지

> 메뉴 위치와 이름은 **2026년 9월 강의 기준**입니다. 화면이 다르게 보이면 최신 내용은 화면에서 직접 확인하세요.

## PART 3. 게임 만들기 실습 (강의 시연 그대로)

강의에서는 **게임**을 골라서 만들어 봤습니다. 똑같이 따라해 봅시다.

### ① 「게임」을 클릭합니다

클로드가 먼저 **"게임 종류가 다양한데 어떤 걸 할까요"**라고 물어봅니다. 무엇을 만들지 정하지 않았어도 괜찮습니다. 클로드가 먼저 물어봐 주니까요.

### ② 어떤 느낌인지 답합니다

강의에서는 이렇게 답했습니다.

```
아케이드 액션 게임, 귀여운 느낌으로 만들어 줘
```

> 여기서 여러분의 취향을 넣으면 됩니다. "퍼즐 게임, 조용한 느낌", "고양이가 나오는 간단한 게임"처럼요.

### ③ 클로드의 제안을 받습니다

클로드가 **「폴짝폴짝 젤리 캐치」**라는 게임을 만들어 주겠다고 제안했습니다.

이때 선택은 두 가지입니다.

- 제안이 마음에 들면 → 그대로 만들어 달라고 합니다
- 마음에 안 들면 → 프롬프트 창에 원하는 걸 적어서 다른 걸 만들어 달라고 합니다

### ④ 「만들어 줘」라고 보냅니다

```
만들어 줘
```

그러면 화면에 이런 일이 일어납니다.

1. **"프론트엔드 디자인 스킬이 로드되었습니다"**라는 문구가 뜹니다
   → 클로드가 화면 디자인을 잘하는 도구를 스스로 꺼내 든 것입니다
2. **게임 HTML 파일을 생성 중**이라고 나옵니다
   → 게임을 담을 파일 하나를 만들고 있다는 뜻입니다
3. 다 만들면 보통은 **코드만** 보입니다
4. 그것을 **클릭하면 실제로 작동하는 모습**이 나타납니다
5. **「코드」** 탭을 누르면 클로드가 짜 놓은 실제 코드도 볼 수 있습니다
6. 게임 화면에서 **「시작하기」**를 누르면 플레이가 시작됩니다

강의에서 만든 게임은 좌우로 왔다 갔다 하면서 떨어지는 젤리를 받는 게임이었습니다.

### 코드가 나와도 겁먹지 마세요

「코드」 탭을 누르면 영어와 기호가 잔뜩 나옵니다. **읽을 필요 전혀 없습니다.**

- 그건 클로드가 자기 손으로 쓴 설계도입니다
- 우리는 **「미리보기」**만 보면 됩니다
- 고치고 싶으면 코드를 건드리는 게 아니라, **말로 부탁하면** 됩니다

## PART 4. 만든 다음이 진짜입니다 — 고쳐 나가기

### 핵심: 채팅에 이어서 말하면 같은 아티팩트가 갱신됩니다

새로 만들라고 하지 마세요. 같은 채팅에서 **"이렇게 바꿔 줘"**라고 이어서 말하면, 옆에 열려 있던 그 아티팩트가 그대로 수정됩니다.

예를 들면 이렇게 말합니다.

```
게임 속도를 조금 느리게 해 줘
```

```
점수판을 화면 위쪽에 크게 보여 줘
```

```
배경색을 파스텔 하늘색으로 바꿔 줘
```

```
젤리 말고 별을 받는 걸로 바꿔 줘
```

### 처음부터 완벽하게 요청하지 마세요

초보자가 가장 많이 하는 실수가 **첫 프롬프트에 원하는 걸 다 우겨 넣는 것**입니다.

| 이렇게 하면 | 이렇게 하세요 |
| --- | --- |
| 첫 요청에 조건 20개를 다 적음 | 일단 간단하게 만들게 함 |
| 결과가 엉뚱하면 처음부터 다시 씀 | 하나씩 "이것만 바꿔 줘"라고 말함 |
| 뭐가 잘못됐는지 알 수 없음 | 한 번에 하나씩 고치니 원인이 보임 |

**만들기 → 보기 → 하나 고치기 → 다시 보기.** 이 순서가 가장 빠릅니다.

## PART 5. 아티팩트로 만들어 볼 만한 것 5가지

게임 말고도 쓸 데가 많습니다. 아래 프롬프트를 그대로 복사해서 써 보세요.

**1. 간단한 계산기**

```
우리 가게 마진율을 계산하는 계산기를 아티팩트로 만들어 줘. 매입가와 판매가를 넣으면 마진과 마진율이 나오게 해 줘
```

**2. 나만의 체크리스트 / 할 일 목록**

```
여행 짐 싸기 체크리스트를 아티팩트로 만들어 줘. 항목을 누르면 체크 표시가 되게 해 줘
```

**3. 표로 정리한 자료**

```
우리 팀 업무 분장표를 표로 정리해서 아티팩트로 만들어 줘
```

**4. 간단한 웹페이지 (미리보기용)**

```
내 소개 페이지를 한 장짜리 웹페이지로 만들어 줘. 이름, 하는 일, 연락 방법이 들어가게 해 줘
```

**5. 아이랑 할 학습 게임**

```
초등학생용 구구단 연습 게임을 아티팩트로 만들어 줘. 귀엽고 정답을 맞히면 칭찬이 나오게 해 줘
```

## 용어 풀이표

| 낱말 | 아주 쉬운 뜻 | 비유 |
| --- | --- | --- |
| 아티팩트 | 클로드가 만든 것을 실제로 작동하는 모습으로 보여 주는, 답변 옆에 따로 열리는 창 | 레시피가 아니라 완성된 요리가 담긴 접시 |
| HTML | 웹페이지를 만드는 기본 파일 형식. 이 파일 하나면 게임도 웹페이지도 열립니다 | 종이 한 장에 그림과 글을 다 담은 것 |
| 미리보기 탭 | 만든 결과물이 실제로 움직이는 화면 | 완성된 요리를 보는 쪽 |
| 코드 탭 | 그 결과물을 만든 실제 코드(설계도). 읽지 않아도 됩니다 | 주방에서 쓴 레시피 종이 |
| 스킬 | 클로드가 특정 일을 잘하도록 미리 준비된 작업 도구. 게임 만들 때 「프론트엔드 디자인 스킬」이 자동으로 불려 왔습니다 | 요리사가 상황에 맞게 꺼내 쓰는 전용 칼 |

> 스킬은 [[06강_스킬 문체 학습과 커넥터 연결]]에서 자세히 다룹니다.

## ⚠️ 주의할 점

- **코드 탭을 억지로 읽으려 하지 마세요.** 이해 못 해도 아무 문제 없습니다. 미리보기만 보면 됩니다.
- **새로 만들라고 하면 정말 새로 만듭니다.** 고치고 싶을 때는 같은 채팅에서 이어서 말해야 원래 아티팩트가 갱신됩니다.
- **무료 사용자는 사용량 한도가 있습니다.** 게임처럼 긴 결과물은 한도를 빨리 씁니다. [[02강_모델 선택과 기본 설정 세팅]]에서 배운 대로 「노력」을 중간이나 끄기로 두면 조금 아낄 수 있습니다.
- **한 번에 다 바꿔 달라고 하지 마세요.** 여러 개를 동시에 고치면 어디가 어긋났는지 찾기 어렵습니다.
- 아티팩트 종류와 메뉴 이름은 **2026년 9월 강의 기준**입니다. 최신 내용은 화면에서 직접 확인하세요.
