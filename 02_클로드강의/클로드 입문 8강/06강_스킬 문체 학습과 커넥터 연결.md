### 오늘의 한 줄

클로드에게 매번 "이렇게 써 줘, 저렇게 써 줘" 설명하는 게 지겨우셨나요? 오늘은 **내 글투를 클로드에게 통째로 가르치는 방법**과, 클로드가 **내 Gmail·구글 드라이브 같은 바깥 서비스를 직접 들여다보게 하는 방법**을 배웁니다. 그리고 아주 중요한 것 하나 — 클로드가 **없는 기능을 있다고 태연하게 말하는 순간**을 실제 사례로 함께 봅니다.

### 오늘 끝나면 이걸 할 수 있습니다

- 「사용자 지정」 메뉴에서 스킬을 찾아 내 계정에 추가할 수 있습니다.
- 새 채팅에서 슬래시(/)를 눌러 설치한 스킬을 불러올 수 있습니다.
- learn 스킬로 내가 쓴 글을 학습시켜 **내 문체로 새 글을 쓰게** 할 수 있습니다.
- 클로드의 답변이 수상할 때 **할루시네이션인지 직접 확인**할 수 있습니다.
- 커넥터를 연결해서 "내 Gmail 제목만 불러와 줘" 같은 일을 시킬 수 있습니다.
- 스킬과 커넥터의 차이를 남에게 한 문장으로 설명할 수 있습니다.

## PART 1. 스킬 — 클로드에게 "일하는 방법"을 알려주는 것

### 스킬이 뭔가요

**스킬은 어떤 일을 처음부터 끝까지 연속으로, 자동으로 해 주는 업무 순서표입니다.**

비유하자면 **요리 레시피 카드**입니다. 카드에는 "재료를 씻고 → 썰고 → 볶고 → 담아낸다"까지 순서가 적혀 있죠. 클로드에게 이 카드를 쥐여 주면, 우리가 매번 "이제 썰어", "이제 볶아"라고 말하지 않아도 알아서 끝까지 갑니다.

지난 시간 [[04강_프로젝트 블로그 글쓰기 시연]]에서 배운 **지침**과 헷갈리기 쉬운데, 이렇게 나눠 보세요.

| 구분 | 하는 일 | 비유 |
| --- | --- | --- |
| 지침 | 그 프로젝트 안에서만 지켜야 할 약속 | 우리 집 냉장고에 붙여둔 쪽지 |
| 스킬 | 어디서든 불러 쓸 수 있는 작업 순서표 | 서랍에 넣어둔 레시피 카드 묶음 |

### 화면 따라하기 — 스킬 추가하기

① 왼쪽 사이드바에서 **「사용자 지정」** 을 클릭합니다.
② 안에 **스킬 / 커넥터 / 플러그인** 세 가지가 보입니다. 그중 **스킬**을 봅니다.
③ **「찾아보기」** 를 클릭합니다.
④ 클로드가 기본으로 만들어 둔 스킬 목록이 나옵니다. (2026년 9월 강의 기준: **캔버스 디자인**, **웹 아티팩트 빌더**, **MCP 빌더** 등)
⑤ 마음에 드는 스킬 오른쪽의 **플러스(+) 버튼**을 누르면 내 계정에 추가됩니다.

> 처음에는 뭐가 뭔지 모르니 **일단 다 추가해 보셔도 됩니다.** 추가한다고 돈이 나가거나 채팅이 느려지지 않습니다. 써 보고 안 쓰는 건 나중에 빼면 됩니다.

### 추가한 스킬을 꺼내 쓰는 법 — 슬래시(/)

① **「새 채팅」** 을 엽니다.
② 프롬프트 창에 키보드로 **슬래시(`/`)** 를 딱 하나 입력합니다.
③ 내가 설치한 스킬 목록이 주르륵 뜹니다.
④ 원하는 스킬을 클릭해서 고른 뒤, 뒤에 이어서 시킬 일을 적습니다.

슬래시 키는 키보드에서 오른쪽 시프트 키 왼쪽에 있는 `/` 입니다. 물음표(`?`) 키와 같은 자리예요.

### 스킬 사용법을 모르겠을 때

가장 쉬운 방법은 **클로드에게 직접 물어보는 것**입니다.

① 슬래시(/)를 눌러 궁금한 스킬을 하나 고릅니다.
② 그대로 이렇게 물어봅니다.

```
이거 어떻게 사용하는 거야?
```

③ 그 스킬이 무슨 일을 하는지, 어떻게 시키면 되는지 설명해 줍니다.

강의에서는 **캔버스 디자인** 스킬에 물어봤더니, 포스터나 아트워크 디자인 결과물을 **PNG·PDF 파일로 만들어 주는 스킬**이라고 답해 주었습니다.

### 스킬을 직접 만들 수도 있습니다

「사용자 지정」 → 스킬 화면에서 스킬을 새로 추가할 때 방법이 세 가지 있습니다.

| 방법 | 이런 분께 |
| --- | --- |
| 업로드 | 이미 만들어진 스킬 파일을 가지고 있는 분 |
| 지침 작성 | 내 업무 순서를 글로 또박또박 쓸 수 있는 분 |
| 클로드와 함께 만들기 | 뭘 써야 할지 모르겠는 분 (가장 추천) |

처음이라면 **「클로드와 함께 만들기」** 를 고르세요. 클로드가 질문을 던지고, 우리는 대답만 하면 스킬이 완성됩니다.

## PART 2. 실습 — learn 스킬로 내 문체 학습시키기

이번 강의의 핵심 실습입니다. **내가 예전에 쓴 글을 클로드에게 읽히면, 앞으로 그 말투로 글을 써 줍니다.**

강사님 설명에 따르면, 예전에는 문체를 따로 등록하는 자리가 있었는데 지금은 그 역할이 **learn 스킬** 안으로 들어왔습니다. (2026년 9월 강의 기준 — 최신 내용은 화면에서 직접 확인하세요.)

### 화면 따라하기 — 다섯 단계

**① 새 채팅에서 슬래시(/)를 누르고 `learn` 스킬을 고릅니다.**

**② 문체를 학습해 달라고 부탁합니다.**

```
문체 스타일을 학습해서 답해 줘
```

**③ 내 글을 넘겨줍니다. 두 가지 방법 중 하나를 고르면 됩니다.**

- 방법 A: 프롬프트 창 왼쪽 **플러스(+) 버튼** → 파일 업로드 (내가 쓴 글 파일)
- 방법 B: 그냥 대화창에 **글 전체를 복사해서 붙여넣기**

그리고 이렇게 말합니다.

```
첨부한 파일을 학습해 봐
```

그러면 클로드가 내 글의 특징을 조목조목 짚어 줍니다. 강의에서는 이런 분석이 나왔습니다.

- 경어체(존댓말)를 사용한다
- 구체적인 장면을 묘사한다
- 최신 사례를 근거로 제시한다

**④ 이 문체를 계속 쓰고 싶다고 물어봅니다.** ← 이 단계가 제일 중요합니다.

```
이 문체를 계속 사용하고 싶은데 어떻게 해야 돼?
```

분석만 받고 끝내면 그 채팅창을 닫는 순간 사라집니다. **"계속 쓰고 싶다"고 말해야** 클로드가 이 문체를 **메모리**에 저장해 둡니다. 메모리는 [[03강_챗GPT 메모리 이전과 채팅 기본]]에서 배운, 클로드가 나에 대해 기억해 두는 수첩입니다.

**⑤ 새 채팅을 열어서 실제로 써먹어 봅니다.**

```
AI를 업무에 활용하는 방법이라는 주제로 내 기고문 문체로 작성해 줘
```

새 채팅인데도 클로드가 아까 배운 문체를 기억하고 있어서, 내가 쓴 것처럼 글을 써 줍니다. 강의에서는 결과물이 [[05강_아티팩트 게임 만들기]]에서 본 **아티팩트** 형태로 나왔습니다.

### 잘 안 될 때 확인할 것

- ④단계를 건너뛰지 않았나요? 저장을 시키지 않으면 기억하지 않습니다.
- 학습시킨 글이 너무 짧지 않나요? 짧은 메모 한 줄로는 문체를 잡아내기 어렵습니다.
- 새 채팅에서 요청할 때 **"내 기고문 문체로"** 처럼 **이름을 불러 주세요.** 그냥 "잘 써 줘"라고 하면 평범한 문체로 돌아갑니다.

### 실습 기록칸 ①

| 항목 | 내가 쓴 것 |
| --- | --- |
| 학습시킨 글 제목 | |
| 클로드가 찾아낸 내 문체 특징 3가지 | 1.<br>2.<br>3. |
| 새 채팅에서 다시 써 봤을 때 느낌 (마음에 든다 / 그저 그렇다) | |

## PART 3. ⚠️ 오늘의 가장 중요한 이야기 — 할루시네이션

> ### 🚨 강의 중 실제로 벌어진 일
>
> ④단계에서 "이 문체를 계속 쓰고 싶은데 어떻게 해?"라고 물었더니, 클로드가 두 가지 방법을 알려줬습니다.
>
> 1. 매번 "이 문체로 써 줘"라고 요청하기
> 2. **"스타일 기능에 이 문체를 등록해 두면 골라 쓸 수 있습니다"**
>
> 그래서 강사님이 "스타일 기능에 넣어 줘"라고 했는데 —
>
> ## **그 「스타일 기능」은 이미 없어진 기능이었습니다.**
>
> 클로드가 **지금은 존재하지도 않는 메뉴를 있는 것처럼 말한 것**입니다.
> 거짓말할 생각이 있어서가 아니라, 아주 자신 있게 틀린 겁니다.
>
> **AI가 하는 말을 전부 믿으면 안 됩니다.**

### ① 할루시네이션이 뭔가요

**할루시네이션(환각)은 AI가 사실이 아닌 것을 아주 자신 있게 말하는 현상**입니다.

가장 가까운 비유는 이렇습니다. 길을 물었는데 **모른다고 말하기 싫은 사람이 "저기서 오른쪽이요"라고 자신 있게 알려주는 것.** 악의는 없습니다. 그런데 우리는 그 말을 믿고 엉뚱한 데로 걸어갑니다.

AI도 똑같습니다. AI는 "모르겠다"고 말하는 것보다 **그럴듯한 문장을 만들어 내는 데 훨씬 익숙**합니다. 그래서 빈칸이 생기면 자연스럽게 채워 넣습니다. 그 채워 넣은 것이 사실이 아닐 때, 그걸 할루시네이션이라고 부릅니다.

**중요한 점: 틀린 답도 맞는 답과 똑같이 술술 나옵니다.** 목소리가 떨리거나 글씨가 흔들리지 않습니다. 그래서 알아채기가 어렵습니다.

### ② AI가 특히 잘 지어내는 것 네 가지

| 종류 | 이런 식으로 지어냅니다 | 오늘 본 사례 |
| --- | --- | --- |
| **없는 기능·메뉴 이름** | "설정에 들어가서 ○○ 기능을 켜세요" — 그런 메뉴가 없음 | **「스타일 기능」** ← 오늘 이것 |
| **숫자·통계** | "국내 사용자의 73%가…" — 근거 없이 만든 숫자 | |
| **출처** | 있어 보이는 책 제목, 논문 이름, 기사 링크를 지어냄 | |
| **최신 정보** | 어제 바뀐 가격·정책을 예전 것으로 자신 있게 답함 | |

특히 **메뉴 이름**은 오늘처럼 조심해야 합니다. AI가 학습할 때는 있었는데 **그 사이에 서비스가 바뀌어 없어진 경우**가 아주 흔하기 때문입니다. 클로드 자신의 기능조차 이렇게 틀립니다.

### ③ 의심스러울 때 확인하는 방법 세 가지

**방법 1. 화면에서 직접 찾아보기 (가장 확실합니다)**

클로드가 "설정 → ○○ 메뉴"라고 하면, 그 자리에서 실제로 설정에 들어가 보세요. **없으면 없는 겁니다.** 클로드가 아니라 내 눈을 믿으세요.

**방법 2. 되물어보기**

찾아봤는데 안 보이면 그대로 물어봅니다.

```
그 메뉴가 지금 화면에 안 보이는데, 정확히 어디에 있어?
```

```
방금 말한 그 기능, 지금도 있는 게 확실해? 없으면 없다고 말해 줘.
```

이렇게 되물으면 "확인해 보니 없을 수 있습니다"라고 물러서는 경우가 많습니다. 그러면 **처음 답이 지어낸 것이었다는 뜻**입니다.

**방법 3. 공식 안내를 확인하기**

가격, 요금제, 기능 유무처럼 **틀리면 손해가 나는 것**은 서비스의 공식 안내 페이지에서 확인하세요. AI의 말은 참고, 공식 페이지가 정답입니다.

### 오늘부터 지킬 습관

- 숫자·가격·날짜가 나오면 → **한 번 더 확인**
- 메뉴 이름이 나오면 → **화면에서 직접 찾아보기**
- 남에게 전달할 내용이면 → **반드시 확인 후 전달**
- 그냥 아이디어를 얻는 용도면 → 편하게 쓰셔도 됩니다

AI는 **똑똑한 조수**이지 **틀리지 않는 사전**이 아닙니다. 최종 확인은 언제나 사람의 몫입니다.

## PART 4. 커넥터 — 클로드를 바깥 서비스에 연결하는 다리

### 커넥터가 뭔가요

**커넥터는 클로드를 내 Gmail·구글 드라이브·슬랙 같은 다른 서비스에 연결해 주는 다리입니다.**

클로드는 원래 자기 채팅창 안에서만 삽니다. 내 메일함이 어떻게 생겼는지, 내 드라이브에 무슨 파일이 있는지 전혀 모릅니다. 커넥터를 놓아 주면 그제서야 **다리를 건너가서 자료를 가져올 수 있게** 됩니다.

### 스킬과 커넥터, 한 문장씩

> **스킬 = 일하는 방법.** 클로드에게 "이런 순서로 일해"라고 알려주는 것.
>
> **커넥터 = 자료를 가져오는 통로.** 클로드에게 "저기 있는 자료를 봐도 돼"라고 문을 열어주는 것.

식당으로 비유하면 **스킬은 레시피**, **커넥터는 식재료 창고 열쇠**입니다. 레시피만 있고 재료가 없으면 요리를 못 하고, 재료만 있고 레시피가 없으면 뭘 만들지 모릅니다. 둘은 서로 다른 물건이고, 함께 쓰면 가장 좋습니다.

### 화면 따라하기 — 커넥터 연결하기

① 왼쪽 사이드바 **「사용자 지정」** → **커넥터**를 클릭합니다.
② **「둘러보기」** 를 클릭하면 이미 만들어져 있는 커넥터 목록이 나옵니다. (2026년 9월 강의 기준: 구글 드라이브, Gmail, 슬랙, 노션, 피그마 등)
③ 연결하고 싶은 것의 **플러스(+) 버튼**을 누릅니다.
④ **그 사이트의 로그인·회원가입 창이 뜹니다.** 여기서 로그인하고 **인증(허용)** 을 눌러 줍니다.
⑤ 인증이 끝나면 연결 완료입니다. 커넥터 목록에 연결된 것으로 표시됩니다.

④단계에서 겁먹지 마세요. 이건 "클로드가 내 Gmail을 봐도 좋다"고 내가 직접 허락 도장을 찍는 절차입니다. 이 절차 없이는 클로드가 절대 내 자료를 볼 수 없습니다.

### 화면 따라하기 — 연결한 커넥터 사용하기

① 채팅 화면에서 프롬프트 창 왼쪽 **플러스(+) 버튼**을 누릅니다.
② **커넥터** 항목이 보입니다. 여기서 이번에 쓸 커넥터를 고릅니다.
③ 굳이 고르지 않고 **전부 선택된 상태로 그냥 대화해도 됩니다.**
④ 평소처럼 프롬프트를 적으면 클로드가 알아서 해당 서비스에 접속합니다.

### 이렇게 시켜 보세요

**Gmail — 오늘 온 메일 제목만 훑어보기**

```
내 Gmail에서 기본 편지함에 있는 이메일의 제목만 불러와 줘
```

**Gmail — 답장을 미리 써서 임시저장 해 두기**

```
오늘 온 메일에 대해서 답장을 작성한 후에 임시저장으로 저장해 놔
```

이건 꽤 놀라운 기능입니다. 클로드가 메일을 **읽고 → 답장을 쓰고 → 임시저장함에 넣어 두기**까지 합니다. 우리는 아침에 임시저장함을 열어서 고칠 데만 고치고 보내면 됩니다.

**캘린더 — 일정 가져오기**

```
오늘 내 캘린더 일정을 정리해서 알려 줘
```

### ⚠️ 커넥터는 개인정보를 다룹니다 — 꼭 읽어 주세요

커넥터를 연결한다는 건 **클로드가 내 메일과 내 문서를 실제로 읽는다**는 뜻입니다. 편리한 만큼 신중해야 합니다.

- **필요한 것만 연결하세요.** "일단 다 연결해 두자"는 스킬에는 괜찮지만 커넥터에는 좋지 않습니다.
- **회사 계정은 한 번 더 생각하세요.** 회사 메일·회사 드라이브는 나 혼자만의 자료가 아닙니다. 사내 규정을 먼저 확인하세요.
- **인증 화면에서 무엇을 허용하는지 읽어보세요.** "메일 읽기"와 "메일 보내기"는 전혀 다른 권한입니다.
- **안 쓰는 커넥터는 끊으세요.** 「사용자 지정」 → 커넥터에서 연결을 해제할 수 있습니다.
- **다른 사람과 함께 보는 화면에서는 커넥터를 쓰지 마세요.** 답변에 내 메일 내용이 그대로 나옵니다.

한마디로: **집 열쇠를 맡기는 일**이라고 생각하시면 됩니다. 필요한 방의 열쇠만, 필요한 기간만 맡기세요.

## ⚠️ 주의할 점

- **클로드가 알려준 메뉴 이름을 그대로 믿지 마세요.** 오늘 본 「스타일 기능」처럼 없어진 기능을 말할 수 있습니다. 반드시 화면에서 직접 확인하세요.
- **문체 학습은 "계속 쓰고 싶다"고 말해야 저장됩니다.** 분석만 받고 창을 닫으면 사라집니다.
- **커넥터는 필요한 것만 연결하세요.** 내 메일과 문서를 실제로 읽습니다.
- **회사 계정 연결은 사내 규정을 먼저 확인하세요.**
- 이 강의에 나온 메뉴 이름·스킬 목록은 **2026년 9월 강의 기준**입니다. 화면이 다를 수 있으니 최신 내용은 직접 확인하세요.
