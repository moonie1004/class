### 오늘의 한 줄

챗GPT를 오래 써 오신 분이라면 "지금까지 챗GPT가 나에 대해 알고 있던 것들, 클로드에서 처음부터 다시 알려 줘야 하나?" 싶어 막막하셨을 겁니다. 그러지 않아도 됩니다. 클로드에는 **메모리를 통째로 옮겨 오는 기능**이 있습니다. 오늘은 그 이사 작업을 마치고, 클로드와 실제로 대화를 주고받는 기본기까지 익힙니다.

### 오늘 끝나면 이걸 할 수 있습니다

- 메모리 기능을 켜고 끌 수 있습니다
- 챗GPT(또는 제미나이)에 쌓인 메모리를 클로드로 옮길 수 있습니다
- 채팅창 왼쪽 **플러스(+)** 버튼으로 파일·사진·스크린샷을 붙일 수 있습니다
- 무료 버전과 유료 버전의 화면이 어떻게 다른지 구분할 수 있습니다
- 내가 보낸 질문을 **수정해서** 다시 답변받을 수 있습니다
- 답변을 복사하고, 소리로 듣고, 좋은 답변/나쁜 답변으로 평가할 수 있습니다

## PART 1. 메모리 — 클로드가 나를 기억하게 하는 스위치

### 메모리가 뭔가요

**메모리는 클로드가 나와 나눈 대화 내용을 기억해 두는 기능입니다.**

메모리가 켜져 있으면, 대화 중에 나온 내용을 클로드가 스스로 메모해 둡니다. 그리고 다음에 다른 대화를 할 때 그 메모를 참고해서 답변합니다.

> 비유하자면 **오래된 단골 가게**입니다. 처음 가는 가게에서는 "저는 매운 거 못 먹어요"를 매번 말해야 하지만, 단골집에서는 사장님이 알아서 순한 맛으로 내어 주시죠. 메모리가 바로 그 역할입니다.

원문 강의에서는 이렇게 설명합니다. "대화에서 메모리를 생성하게 되면 내 채팅 내용을 기반으로 그걸 기억해서 답변을 해 주기 때문에, **업무 등에서 사용하시려면 켜 두시는 게 좋습니다.**"

### 메모리는 어디에 있나요

[[02강_모델 선택과 기본 설정 세팅]]에서 다녀왔던 그 설정 화면 안에 있습니다.

**화면 따라하기**

① 왼쪽 아래 **내 이름** 클릭
② **설정** 클릭
③ 기능 관련 항목들을 아래로 내려 보면 **스킬 / 커넥터 / 플러그인 / 메모리**가 보입니다
④ **메모리**를 클릭합니다

> 메뉴 위치는 2026년 9월 강의 기준입니다. 클로드는 화면이 자주 바뀌므로, 안 보이면 설정 안을 위아래로 천천히 훑어보세요.

### 켜면 좋은 경우 / 끄는 게 나은 경우

| 상황 | 메모리 | 왜 그런가요 |
| --- | --- | --- |
| 업무에 계속 쓸 때 | ✅ 켜기 | 내 직무·회사·말투를 매번 설명하지 않아도 됩니다 |
| 블로그·글쓰기처럼 내 스타일이 중요한 일 | ✅ 켜기 | 한 번 알려 준 문체를 다음에도 기억합니다 |
| 진행 중인 프로젝트가 여러 회차로 이어질 때 | ✅ 켜기 | "지난번 그거"라고만 해도 알아듣습니다 |
| 회사 기밀·고객 개인정보를 다룰 때 | ⬜ 끄기 | 남는 기록을 최소화하는 편이 안전합니다 |
| 남의 계정을 잠깐 빌려 쓸 때 | ⬜ 끄기 | 내 정보가 그 계정에 남습니다 |
| 평소와 전혀 다른 실험을 해 볼 때 | ⬜ 끄기 | 엉뚱한 내용이 기억으로 굳어질 수 있습니다 |

기본은 **켜 두기**입니다. 민감한 작업을 할 때만 잠깐 끄면 됩니다.

## PART 2. 챗GPT·제미나이 메모리 이사시키기

챗GPT를 메인으로 쓰셨다면, 그동안 챗GPT가 나에 대해 알고 있던 게 꽤 많습니다. 그걸 클로드에 그대로 옮길 수 있습니다.

### 큰 그림 먼저

이사는 **세 곳을 왔다 갔다** 합니다. 이게 헷갈리는 지점이니 그림처럼 외워 두세요.

```
[클로드] 안내 문구 복사
   ↓ 붙여넣기
[챗GPT] 내 메모리를 정리해서 보여 줌 → 그 결과 복사
   ↓ 붙여넣기
[클로드] 메모리로 저장 완료
```

즉 **클로드 → 챗GPT → 클로드** 순서입니다. 한 바퀴 돌아서 제자리로 옵니다.

### 화면 따라하기 (아주 자세히)

**① 클로드 설정에서 메모리 화면으로 갑니다**

왼쪽 아래 **내 이름** → **설정** → **메모리**.
그 안에 **「가져오기 시작」** 버튼이 있습니다. 이걸 누릅니다.

**② 화면에 나타난 안내 문구를 복사합니다**

버튼을 누르면 **글자 덩어리(안내 문구)** 가 하나 나옵니다. 이건 "챗GPT야, 네가 나에 대해 기억하고 있는 걸 정리해서 알려 줘"라는 뜻의 부탁 문장, 즉 **프롬프트**입니다.

- 옆에 **복사 버튼**이 있으면 그걸 누릅니다
- 없으면 문구 전체를 마우스로 드래그해서 선택 → `Ctrl + C` (맥은 `Cmd + C`)

> ⚠️ 여기서 가장 많이 하는 실수: 이 문구를 **클로드 채팅창에 그대로 붙여넣는 것**입니다. 아닙니다. 이건 **챗GPT에 줄 편지**입니다. 클로드 화면은 잠깐 그대로 두세요.

**③ 챗GPT로 가서 붙여넣고 보냅니다**

새 탭을 열어 챗GPT에 로그인합니다. (제미나이를 쓰셨다면 제미나이로 가시면 됩니다.)
채팅 입력창에 `Ctrl + V`로 붙여넣고 **보내기**를 누릅니다.

**④ 챗GPT가 정리해 준 결과를 복사합니다**

잠시 기다리면 챗GPT가 **자기가 기억하고 있던 내 정보를 쭉 정리해서** 답변으로 보여 줍니다. 원문 강의에서는 "이런 식으로 정리를 싹 해 줬고요"라고 표현합니다.

- 답변 아래쪽 **복사 아이콘**을 누릅니다
- 아이콘을 못 찾겠으면 답변 전체를 드래그해서 `Ctrl + C`

**⑤ 클로드로 돌아와 붙여넣습니다**

②에서 열어 둔 클로드의 메모리 가져오기 화면(또는 안내에 나온 입력칸)에 `Ctrl + V`로 붙여넣습니다.
그러면 클로드가 그 내용을 읽고 **자기 메모리로 저장**합니다.

이것으로 끝입니다. 원문 표현 그대로 "**똑같은 환경처럼 사용할 수 있습니다.**"

### 옮긴 뒤에 꼭 할 일

옮겨 온 내용은 **한 번 훑어보세요.** 챗GPT가 잘못 기억하고 있던 것, 이제는 사실이 아닌 것(예전 직장, 옛날 관심사)이 섞여 있을 수 있습니다. 필요 없는 건 메모리 화면에서 지우면 됩니다.

> 「가져오기 시작」이라는 메뉴 이름과 화면 구성은 2026년 9월 강의 기준입니다. 최신 내용은 화면에서 직접 확인하세요.

## PART 3. 채팅 기본 — 플러스(+) 버튼 열어 보기

이제 설정은 끝났습니다. 실제로 대화하는 화면을 봅니다.

모델은 이미 선택되어 있는 상태입니다. (모델 고르는 법은 [[02강_모델 선택과 기본 설정 세팅]] 참고)

### 플러스(+) 버튼

프롬프트 창 **왼쪽의 플러스(+)** 버튼을 눌러 보세요. 무료 버전 기준으로 이런 것들이 나옵니다.

| 메뉴 | 무엇을 하나요 | 이럴 때 씁니다 |
| --- | --- | --- |
| 파일이나 사진 추가 | 내 컴퓨터 파일을 클로드에게 보여 줍니다 | 보고서 요약, 엑셀 정리, 사진 속 글자 읽기 |
| 스크린샷 캡처 | 지금 화면을 찍어서 바로 첨부합니다 | "이 오류 화면 뭐야?" 물어볼 때 |
| 프로젝트 만들기 | 주제별 작업 공간을 만듭니다 | [[04강_프로젝트 블로그 글쓰기 시연]]에서 자세히 |
| 스킬 연결 | 정해진 작업 순서를 불러옵니다 | [[06강_스킬 문체 학습과 커넥터 연결]] |
| 커넥터 연결 | 지메일·드라이브 같은 외부 서비스를 연결합니다 | [[06강_스킬 문체 학습과 커넥터 연결]] |
| 플러그인 연결 | 스킬·커넥터를 묶은 꾸러미를 붙입니다 | [[07강_플러그인과 유료 기능 총정리]] |

지금은 **파일·사진 추가**와 **스크린샷 캡처** 두 가지만 확실히 익혀 두시면 충분합니다. 나머지는 뒤 강의에서 하나씩 다룹니다.

### 무료 버전 vs 유료 버전 — 화면이 다릅니다

무료로 쓰다가 유료로 올리면 "화면이 왜 달라졌지?" 하고 당황하실 수 있어 미리 정리합니다.

| 비교 항목 | 무료 버전 | 유료 버전 |
| --- | --- | --- |
| 프롬프트 창 | 채팅 하나 | **채팅 / 코워크** 두 개로 분리 |
| 왼쪽 사이드바 | 채팅·프로젝트·아티팩트·사용자 지정 | 여기에 **예정됨**이 추가 |
| 클로드 코드 | 업그레이드 필요 | **따로 빠져 있음** |
| 클로드 디자인 | 사용 불가 | 사이드바 **제일 아래**에 있음 |
| 모델 선택 | 일부만 | 모델·노력 수준을 **전부** 선택 가능 |
| 플러스(+) 메뉴 | 위 표의 항목들 | 여기에 **「연구」**, **깃허브 추가**가 더 있음 |

**「연구」가 뭔가요?**
→ **딥 리서치 기능입니다.** 클로드가 웹을 여러 번 찾아보고 조사해서 긴 보고서처럼 답을 만들어 줍니다. 챗GPT의 "심층 리서치"와 같은 기능이라고 보시면 됩니다.

> 화면 구성은 2026년 9월 강의 기준입니다. 최신 내용은 화면에서 직접 확인하세요.
> 유료 기능은 [[07강_플러그인과 유료 기능 총정리]], 코워크는 [[08강_코워크 데스크톱 앱과 대시보드]]에서 이어집니다.

## PART 4. 대화 주고받기와 답변 다루기

### ① 일단 말을 걸어 봅니다

프롬프트 창에 아무거나 적고 보내 보세요.

```
안녕, 반가워
```

답이 오면 그 아래에 또 적습니다. 사람과 대화하듯 계속 이어 나가면 됩니다. **한 화면 안에서 오간 이야기는 클로드가 다 기억한 채로 답합니다.**

### ② 내가 보낸 질문 수정하기 — 오늘의 숨은 보물

내가 이미 보낸 질문 위에 마우스를 올리면 **수정** 아이콘이 나타납니다. 눌러서 질문을 고치고 **저장**하면, 클로드가 **고친 질문으로 다시 답변**합니다.

**왜 유용한가요?**

| 이런 상황 | 수정 기능이 없다면 | 수정 기능을 쓰면 |
| --- | --- | --- |
| 질문에 오타를 냈다 | 다시 길게 타이핑 | 글자만 고치고 저장 |
| 답이 너무 길게 나왔다 | "짧게 해 줘"를 또 보냄 | 원래 질문에 "500자로"만 추가 |
| 방향을 완전히 바꾸고 싶다 | 새 대화를 열고 처음부터 설명 | **앞의 맥락은 그대로 두고 방향만 변경** |

핵심은 이겁니다. **새 대화를 열지 않고도 방향만 바꿀 수 있다**는 것. 새 대화를 열면 여태 쌓아 둔 설명과 파일을 다시 붙여야 하지만, 질문 수정은 그 수고 없이 갈래만 바꿉니다. 답이 마음에 안 들 때 "새 채팅"부터 누르는 습관이 있다면, 오늘부터 **수정 → 저장**을 먼저 눌러 보세요.

### ③ 메모리가 저장되는 걸 눈으로 확인하기

대화를 하다 보면 **채팅 내역 화면에서 클로드가 자동으로 메모리를 저장해 두는 모습**을 볼 수 있습니다. 내가 따로 "기억해 줘"라고 하지 않아도, 기억해 둘 만하다고 판단하면 알아서 저장합니다.

PART 1에서 메모리를 켜 두었기 때문에 생기는 일입니다. 잘 켜졌는지 확인하는 가장 쉬운 방법이기도 합니다.

### ④ 답변 아래 버튼 3종

답변 아래쪽에 작은 아이콘들이 있습니다.

| 버튼 | 하는 일 | 이럴 때 |
| --- | --- | --- |
| 복사 | 답변 내용을 **그대로 전부** 복사 | 워드·메일·블로그에 옮겨 붙일 때 |
| 소리로 듣기 | 답변을 음성으로 읽어 줍니다 | 눈이 피곤할 때, 이동 중일 때 |
| 좋은 답변 / 나쁜 답변 | 답변 품질을 평가합니다 | 마음에 들었을 때 / 엉뚱했을 때 |

평가 버튼은 눌러도 손해가 없습니다. 마음에 들면 **좋은 답변**, 엉뚱하면 **나쁜 답변**을 눌러 주세요.

## ⚠️ 주의할 점

- **복사·붙여넣기 방향을 헷갈리지 마세요.** 클로드에서 복사한 문구는 **챗GPT에** 붙여넣고, 챗GPT가 정리해 준 결과는 **클로드에** 붙여넣습니다. 한 바퀴입니다.
- **옮겨 온 메모리를 그대로 믿지 마세요.** 오래돼서 틀린 정보가 섞여 있을 수 있습니다. 한 번 읽어 보고 필요 없는 건 지웁니다.
- **회사 기밀이나 고객 개인정보를 다루는 대화에서는 메모리를 잠깐 꺼 두세요.** 기록이 남습니다.
- **메모리는 만능이 아닙니다.** 중요한 지시는 대화마다 다시 한 번 짚어 주는 편이 안전합니다. 진짜 고정으로 쓸 규칙은 프로젝트 지침에 넣는 편이 확실합니다. ([[04강_프로젝트 블로그 글쓰기 시연]])
- **메뉴 이름과 위치는 2026년 9월 강의 기준입니다.** 화면이 다르면 설정 안을 천천히 훑어보시거나, 클로드에게 "메모리 설정 어디 있어?"라고 물어보셔도 됩니다.
