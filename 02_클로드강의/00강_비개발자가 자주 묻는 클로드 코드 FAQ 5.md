### 오늘의 한 줄

클로드 코드를 배우려는데 **말부터 막힙니다.** 터미널, CLI, IDE… 이게 다 뭔지 모르면 첫 화면에서 멈추게 돼요. 오늘은 **설치하기 전에** 이 낱말들을 하나씩 풀어봅니다. 설치는 다음 시간에 합니다.

### 오늘 끝나면 이걸 할 수 있습니다

- 클로드 / 클로드 데스크톱 / 클로드 코드가 어떻게 다른지 설명할 수 있다
- 터미널을 직접 열어 명령 세 줄을 쳐볼 수 있다
- CLI와 GUI의 차이를 내 말로 말할 수 있다
- IDE가 뭔지, 왜 개발자들이 그걸 쓰는지 안다
- 나는 터미널로 시작할지 IDE로 시작할지 스스로 정할 수 있다

> 이 자료의 화면·기능 설명은 2026년 9월 공식 문서 기준입니다. 클로드는 자주 바뀌니, 자료와 화면이 다르면 화면을 믿고 진행하세요.

## PART 0. 먼저 큰 그림부터

낱말 다섯 개가 헷갈리는 이유는, **서로 종류가 다른 것들을 나란히 놓고 비교**하기 때문입니다. 정리하면 이렇습니다.

| 낱말 | 이게 무엇인가 |
| --- | --- |
| **클로드** | AI 그 자체 (사람으로 치면 '사람') |
| **클로드 코드** | 그 AI를 쓰는 **프로그램** 중 하나 |
| **클로드 데스크톱** | 그 AI를 쓰는 **또 다른 프로그램** |
| **터미널** | 프로그램을 실행하는 **장소** (문자로 명령하는 창) |
| **CLI** | 프로그램을 **다루는 방식** (문자로) |
| **IDE** | 개발자용 **작업실 프로그램** (여기 안에도 터미널이 들어 있음) |

> 🏠 **비유** — 클로드는 **요리사**입니다. 이 요리사를 **어디서, 어떻게 부르느냐**가 나머지 낱말들이에요. 전화로 부르느냐(터미널), 가게에 찾아가느냐(앱), 부엌까지 들어와 달라고 하느냐(IDE). 요리사는 같은 사람입니다.

## PART 1. ❓ 클로드랑 클로드 코드랑 무슨 차이예요?

### 1-1. 한 문장 답

> **클로드는 "말로 도와주는 AI"이고, 클로드 코드는 "내 컴퓨터에서 직접 손을 쓰는 AI"입니다.**

### 1-2. 뭐가 다른지 표로

| | 클로드 (claude.ai) | 클로드 코드 |
| --- | --- | --- |
| 어디서 쓰나 | 웹 브라우저, 휴대폰 앱 | 내 컴퓨터의 **터미널** |
| 화면 | 채팅창 | 문자만 있는 검은 창 |
| 파일을 볼 수 있나 | 내가 **올려줘야** 봄 | 내 폴더를 **스스로 열어서** 봄 |
| 파일을 고칠 수 있나 | ❌ (고친 내용을 복사해 줌) | ⭕ **직접 고쳐서 저장함** |
| 프로그램을 실행할 수 있나 | ❌ | ⭕ (설치, 실행, 테스트) |
| 결과가 어디 남나 | 대화창 안에 | **내 컴퓨터 파일로** |
| 필요한 것 | 무료도 가능 | **유료 구독 필요** |

### 1-3. 같은 부탁을 했을 때

**"이 파일에서 오타 좀 고쳐줘"라고 했다면**

| | 클로드 | 클로드 코드 |
| --- | --- | --- |
| ① | 내가 파일을 올린다 | "그 파일 고쳐줘"라고 말만 한다 |
| ② | 클로드가 고친 내용을 보여준다 | 클로드 코드가 **파일을 직접 열어** 읽는다 |
| ③ | **내가** 복사해서 붙여넣는다 | **클로드 코드가** 고쳐서 저장한다 |
| ④ | **내가** 저장한다 | 끝 |

> 💬 이 차이 하나가 전부입니다. **말해주는 AI**와 **일해주는 AI**의 차이예요.

### 1-4. 그럼 클로드 코드는 개발자만 쓰나요?

아닙니다. 이름에 '코드'가 붙어서 오해하기 쉬운데, **파일을 다루는 일이면 뭐든** 시킬 수 있습니다.

| 비개발자도 하는 일 | 예 |
| --- | --- |
| 폴더 정리 | "다운로드 폴더의 사진을 찍은 달별로 나눠줘" |
| 문서 변환 | "이 폴더의 워드 파일 30개를 전부 PDF로 바꿔줘" |
| 자료 취합 | "월별 엑셀 12개를 하나로 합쳐줘" |
| 자료 찾기 | "계약서 폴더에서 '위약금'이 나오는 문서만 찾아줘" |
| 이름 바꾸기 | "파일 이름 앞에 날짜를 붙여줘" |

이런 일은 사람이 하면 한 시간, 클로드 코드는 몇 분입니다.

## PART 2. ❓ 클로드 데스크톱이랑 클로드 코드랑 무슨 차이예요?

### 2-1. 헷갈리는 이유

둘 다 **내 컴퓨터에 설치**하고, 둘 다 **내 파일을 만질 수 있어서** 헷갈립니다. 하지만 목적이 다릅니다.

### 2-2. 한 문장 답

> **클로드 데스크톱은 "버튼으로 쓰는 클로드"이고, 클로드 코드는 "글자로 시키는 클로드"입니다.**

### 2-3. 비교표

| | 클로드 데스크톱 앱 | 클로드 코드 |
| --- | --- | --- |
| 생김새 | 웹 클로드와 **똑같은 채팅 화면** | 검은 터미널 창, 글자만 |
| 마우스 | 씀 (버튼 클릭) | 거의 안 씀 (타자) |
| 내 파일 | **코워크** 기능으로 폴더 연결 | 실행한 폴더를 바로 다룸 |
| 잘하는 일 | 문서 작성, 자료 정리, 대시보드 | 파일 대량 처리, 프로그램 실행, 개발 |
| 명령 실행 | 제한적 | **자유롭게** (설치·실행·테스트) |
| 배우기 | 쉬움 | 처음엔 낯섦 |
| 결과물 | 채팅 + 내 폴더 파일 | 내 폴더 파일 |

> 💬 [[08강_코워크 데스크톱 앱과 대시보드]]에서 배운 코워크가 바로 **데스크톱 앱**으로 하는 일입니다.

### 2-4. 그림으로 보면

```
        [ 클로드 = 같은 AI ]
                 │
    ┌────────────┼────────────┐
    │            │            │
 웹 클로드   데스크톱 앱   클로드 코드
 (브라우저)   (버튼으로)   (글자로)
    │            │            │
 파일 올림    폴더 연결    폴더에서 실행
```

**셋 다 같은 AI입니다.** 부르는 방법만 다릅니다.

### 2-5. 나는 뭘 써야 하나

| 나는 이렇다 | 추천 |
| --- | --- |
| AI를 처음 쓴다 | **웹 클로드** |
| 내 폴더 문서를 정리하고 싶다 | **데스크톱 앱(코워크)** |
| 파일 수십 개를 한 번에 처리하고 싶다 | **클로드 코드** |
| 프로그램을 만들거나 고치고 싶다 | **클로드 코드** |

## PART 3. ❓ 터미널은 뭐예요?

### 3-1. 한 문장 답

> **터미널은 컴퓨터에게 "글로 심부름을 시키는 창"입니다.**

### 3-2. 우리가 평소에 하는 방식과 비교

폴더 안에 뭐가 있는지 보고 싶을 때,

| 평소 방식 | 터미널 방식 |
| --- | --- |
| 탐색기를 연다 → 폴더를 더블클릭한다 → 눈으로 본다 | `ls` 라고 치고 엔터 |

**결과는 똑같습니다.** 마우스로 하느냐, 글자로 하느냐의 차이예요.

> 🗣️ **비유** — 식당에서 메뉴판을 손가락으로 가리키는 것(마우스)과, "김치찌개 하나요"라고 말하는 것(터미널)의 차이입니다. 말로 하는 게 익숙해지면 훨씬 빠릅니다.

### 3-3. 왜 굳이 이걸 쓰나요?

| 이유 | 설명 |
| --- | --- |
| **빠르다** | 파일 500개 이름 바꾸기 → 마우스로 500번 vs 한 줄 |
| **반복이 쉽다** | 한 번 만든 명령을 매일 다시 쓸 수 있음 |
| **정확하다** | 무엇을 했는지 글자로 남음 |
| **어쩔 수 없다** | 클로드 코드처럼 **터미널에서만 되는 프로그램**이 있음 |

### 3-4. 내 컴퓨터에서 터미널 열어보기

이름이 컴퓨터마다 다릅니다. **다 같은 것**입니다.

| 내 컴퓨터 | 프로그램 이름 | 여는 법 |
| --- | --- | --- |
| 윈도우 | **PowerShell** 또는 Windows 터미널 | 시작 메뉴에서 "PowerShell" 검색 |
| 윈도우 (다른 방법) | — | 폴더 빈 공간 **오른쪽 클릭 → "터미널에서 열기"** |
| 맥 | **터미널(Terminal)** | Command + Space → "터미널" 검색 |

### 3-5. 🖐️ 함께 해보기 — 무서운 창이 아닙니다

터미널을 열고 아래를 **한 줄씩** 쳐보세요. 아무것도 망가지지 않습니다.

**① 지금 내가 어느 폴더에 있나?**

```
pwd
```

**② 이 폴더 안에 뭐가 있나?**

```
ls
```

윈도우 PowerShell에서 `ls`가 안 되면 `dir`을 쳐보세요.

**③ 오늘 날짜가 뭐지?**

```
date
```

### ✏️ 해보고 적기

| 명령 | 화면에 뭐가 나왔나 |
| --- | --- |
| `pwd` | |
| `ls` | |
| `date` | |

> 😌 **겁먹지 마세요.** 위 세 개는 **읽기만 하는 명령**입니다. 지우거나 바꾸지 않아요. 뭘 잘못 쳐도 대부분은 "그런 명령 없다"는 메시지만 나옵니다.

### 3-6. ⚠️ 딱 하나만 조심

터미널은 **되돌리기(Ctrl+Z)가 없습니다.** 지우는 명령을 실행하면 휴지통도 안 거치고 사라질 수 있어요.

**그래서 이렇게 하세요.**

- 인터넷에서 본 명령을 **뜻도 모르고 붙여넣지 않기**
- 모르는 명령은 **클로드에게 "이 명령 뭐 하는 거야?"라고 먼저 물어보기**
- 중요한 폴더 말고 **연습용 폴더**를 하나 만들어서 거기서 시작하기

## PART 4. ❓ CLI는 뭐예요?

### 4-1. 한 문장 답

> **CLI는 "글자로 프로그램을 다루는 방식"입니다.** Command Line Interface, 우리말로 **명령줄 인터페이스**예요.

낱말을 쪼개면 이렇습니다.

| 영어 | 뜻 |
| --- | --- |
| Command | 명령 |
| Line | 줄 |
| Interface | 사람과 기계가 만나는 지점 |

→ **"한 줄씩 명령해서 쓰는 방식"**

### 4-2. 짝이 되는 낱말 — GUI

| | **CLI** (명령줄) | **GUI** (그래픽) |
| --- | --- | --- |
| 읽는 법 | 씨엘아이 | 지유아이 |
| 어떻게 쓰나 | 글자를 친다 | 버튼을 누른다 |
| 예 | 터미널, 클로드 코드 | 카카오톡, 한글, 웹 클로드 |
| 배우기 | 어렵다 | 쉽다 |
| 익숙해지면 | 훨씬 빠르다 | 반복이 느리다 |

> 🚗 **비유** — GUI는 **자동 변속기**, CLI는 **수동 변속기**입니다. 자동이 쉽지만, 수동은 익숙해지면 원하는 대로 정밀하게 다룰 수 있어요.

### 4-3. 터미널과 CLI는 뭐가 다른가요?

가장 많이 헷갈리는 부분입니다.

| | 터미널 | CLI |
| --- | --- | --- |
| 정체 | **창(프로그램)** | **방식(개념)** |
| 비유 | 무대 | 연극 형식 |
| 문장으로 | "터미널을 **연다**" | "클로드 코드는 **CLI 도구다**" |

**클로드 코드는 CLI 도구이고, 그것을 실행하는 창이 터미널입니다.**

### 4-4. 덤 — IDE도 알아두면 좋습니다

**IDE**는 Integrated Development Environment, **통합 개발 환경**입니다.

> 🧰 **비유** — **공구함**입니다. 망치, 드라이버, 줄자를 따로 들고 다니지 않고 한 상자에 넣어 둔 것.

프로그램을 만들 때 필요한 것들이 한 창에 다 들어 있습니다.

| IDE 안에 든 것 | 하는 일 |
| --- | --- |
| 파일 목록 | 왼쪽에 폴더 구조가 보임 |
| 편집기 | 글자를 색깔로 구분해서 보여줌 |
| **터미널** | ⭐ IDE 안에도 터미널이 들어 있음 |
| 실행·검사 도구 | 만든 걸 바로 돌려보고 오류를 찾음 |

대표적인 IDE가 **VS Code**(브이에스 코드)입니다. 무료이고 가장 많이 씁니다. **Antigravity**는 구글이 만든 AI 중심 코드 편집기인데, VS Code를 바탕으로 만들어졌습니다.

> 📌 **여기가 중요합니다** — IDE 안에 터미널이 들어 있다는 것. 그래서 **IDE를 열고 그 안에서 클로드 코드를 실행할 수 있습니다.** 다음 질문의 답이 여기서 나옵니다.

## PART 5. ❓ Antigravity·VS Code에서 쓰는 거랑 터미널이랑 차이가 있어요?

### 5-1. 한 문장 답

> **속은 완전히 똑같습니다. 겉모습과 편의 기능만 다릅니다.**

같은 클로드 코드가 돌아갑니다. 성능도, 할 수 있는 일도, 쓰는 사용량도 같아요.

### 5-2. 그럼 뭐가 다른가

| | 터미널에서 그냥 실행 | VS Code 확장 프로그램으로 |
| --- | --- | --- |
| 화면 | 검은 창에 글자만 | 편집기 옆에 **패널**로 붙음 |
| **고친 내용 확인** | 글자로 설명 | **바뀌기 전/후를 나란히** 보여줌 ⭐ |
| 파일 지정 | 경로를 직접 타자 | 마우스로 **선택하면 자동 인식** |
| 여러 대화 | 창을 여러 개 | **탭으로** 나란히 |
| 계획 검토 | 글자로 | **문서로 열어 의견 달기** |
| 설치 | 클로드 코드만 | 편집기 + 확장 프로그램 |
| 가벼움 | ⭐ 아주 가벼움 | 무거움 |

### 5-3. 무엇을 얻는가 — 딱 하나만 꼽자면

**"바뀌기 전과 후를 나란히 보여주는 것"**입니다.

터미널에서는 클로드 코드가 "이 파일의 12번째 줄을 이렇게 바꿨습니다"라고 **글자로** 알려줍니다. VS Code에서는 **왼쪽에 원래 내용, 오른쪽에 바뀔 내용**이 색깔로 표시돼요. 승인하기 전에 눈으로 확인할 수 있습니다.

파일을 고치는 일이 많다면 이게 큰 차이입니다.

### 5-4. Antigravity에서도 되나요?

**아마 됩니다.** 이유는 이렇습니다.

- Antigravity는 **VS Code를 바탕으로 만든 편집기**입니다
- 공식 문서는 VS Code, Cursor, JetBrains를 안내하면서, **"다른 VS Code 계열 편집기에도 설치된다"**고 밝히고 있습니다
- 편집기의 확장 프로그램 목록에서 "Claude Code"를 검색하거나, Open VSX라는 저장소에서 설치합니다

**만약 확장 프로그램이 설치되지 않는다면?** 공식 문서가 답을 줍니다.

> 클로드 코드 본체(CLI)를 설치하고, 그 편집기의 **내장 터미널**에서 `claude`를 실행하면 됩니다. CLI는 **어떤 터미널에서든** 동작합니다.

즉 **어느 편집기를 쓰든 막히지 않습니다.** 확장 프로그램이 되면 편하게, 안 되면 그 안의 터미널에서 쓰면 돼요.

### 5-5. 그럼 나는 뭘로 시작할까

| 나는 이렇다 | 추천 |
| --- | --- |
| 코딩을 안 한다. 파일 정리·문서 작업이 목적이다 | **터미널** — 편집기까지 설치할 필요 없음 |
| 클로드 코드가 뭘 바꾸는지 눈으로 확인하고 싶다 | **VS Code + 확장** |
| 이미 VS Code나 Antigravity를 쓰고 있다 | **거기서 바로** |
| 컴퓨터가 느리다 | **터미널** — 훨씬 가벼움 |
| 잘 모르겠다 | **터미널로 시작** → 답답해지면 그때 편집기로 |

> 💬 **강사 조언** — 처음엔 터미널을 권합니다. 설치할 게 하나뿐이고, 터미널에 익숙해지면 나중에 어떤 편집기를 쓰든 헤매지 않습니다. 반대로 편집기부터 시작하면 **뭐가 편집기 기능이고 뭐가 클로드 코드 기능인지** 구분이 안 됩니다.

> **클로드 코드는 CLI 도구다. 그걸 실행하는 창이 터미널이고, IDE 안에도 그 창이 들어 있다.**

## ⚠️ 오늘 꼭 기억할 세 가지

**1. 클로드 코드는 유료 구독이 필요합니다.** 프로 이상 플랜이 있어야 쓸 수 있고, 대신 API 요금이 따로 나가지는 않습니다. 구독에 포함된 사용량으로 돕니다.

**2. 터미널은 되돌리기가 없습니다.** 뜻 모르는 명령을 붙여넣지 마세요. 모르겠으면 클로드에게 먼저 물어보세요.

**3. 어떤 방법으로 쓰든 클로드는 같습니다.** 터미널이든 VS Code든 Antigravity든, 능력 차이는 없습니다. **화면이 편한 쪽을 고르면 됩니다.**
