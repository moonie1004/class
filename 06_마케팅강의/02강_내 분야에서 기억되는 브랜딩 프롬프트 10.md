| 이름 | |
| 준비물 | 노트북, 챗GPT(또는 클로드) 계정, 내 경험을 적을 메모 |

### 오늘의 한 줄

콘텐츠는 꾸준히 만드는데 **"왜 나는 기억에 남지 않을까"** 싶다면, 문제는 개수가 아닙니다. **내 포지션을 정하고 → 반복해서 보여주고 → 신뢰를 쌓는** 과정이 빠진 거예요. 오늘은 그 과정을 프롬프트 10개로 순서대로 만듭니다.

### 오늘 끝나면 이걸 할 수 있습니다

- 나를 한 문장으로 설명하는 포지셔닝 문장을 만들 수 있다
- 30일 콘텐츠 플랜과 주간 반복 루틴을 갖는다
- "이 주제 하면 이 사람"이 되는 시그니처 주제 5개를 정한다
- 내 경험 하나를 여러 콘텐츠로 바꿀 수 있다
- 대놓고 팔지 않으면서 문의로 이어지는 콘텐츠를 설계할 수 있다

---

## PART 0. 순서가 중요합니다

10개를 한 번에 입력하지 마세요. **1번부터 순서대로** 실행합니다. 앞의 답이 뒤의 재료가 되기 때문입니다.

| 단계 | 프롬프트 | 무엇이 나오나 |
| --- | --- | --- |
| **1단계 — 정하기** | 01 · 02 | 포지셔닝 문장, 30일 콘텐츠 플랜 |
| **2단계 — 쌓기** | 03 · 04 · 05 | 권위 전략, 네트워크 계획, 주간 루틴 |
| **3단계 — 강화하기** | 06 · 07 · 08 | 시그니처 주제, 경쟁 분석, 저장되는 콘텐츠 30개 |
| **4단계 — 연결하기** | 09 · 10 | 경험의 콘텐츠화, 수익화 연결 |

### ⭐ 시작 전에 이것부터 입력하세요

GPT가 내 상황을 모르는 채로 답하면 뻔한 결과가 나옵니다. **1번을 넣기 전에** 아래를 먼저 넣으세요.

```
지금부터 나의 분야와 브랜드를 함께 정리할 거야.
내가 답한 내용과 앞에서 나눈 대화를 계속 참고해서 다음 질문에 답해줘.
정보가 부족하면 임의로 가정하지 말고 나에게 먼저 질문해줘.
```

> 💬 마지막 줄이 핵심입니다. **"모르면 지어내지 말고 물어봐"**라고 미리 못 박는 것. 이게 없으면 AI가 없는 내 경력을 상상해서 채웁니다.

## 1단계 · 정하기

### 01. 나만의 브랜드 포지셔닝 정하기

```
내 분야, 가치관, 강점, 그리고 타깃 독자에 대해 5가지 질문을 해줘.
그다음 답변을 바탕으로 나를 잊지 않게 만드는 개인 포지셔닝 문장을 정의해줘.
```

> 💡 **이렇게 활용하세요** — 처음부터 "내 브랜딩 해줘"라고 하지 말고, **질문을 먼저 받는 방식**으로 시작하세요. 내가 미처 생각하지 못했던 강점이나 차별점을 발견하기 좋습니다.

#### ✏️ 내 포지셔닝 문장

| 항목 | 내 답 |
| --- | --- |
| 내 분야 | |
| 내 강점 | |
| 타깃 독자 | |
| **완성된 포지셔닝 한 문장** | |

### 02. 하나의 강점을 제안으로 바꾸기

```
[분야]에서 나를 전문가로 포지셔닝할 수 있는 30일 콘텐츠 플랜을 만들어줘.
훅, 형식, 그리고 빠르게 신뢰를 쌓는 CTA까지 포함해줘.
```

> 💡 **이렇게 활용하세요** — 내 강점을 단순한 '소개'로 끝내지 말고, 사람들에게 계속 보여줄 **콘텐츠**로 바꾸세요.

| 이렇게 말하면 ❌ | 이렇게 바꾸면 ⭕ |
| --- | --- |
| 정리 잘하는 사람 | **좁은 집을 효율적으로 쓰는 정리 노하우를 알려주는 사람** |

강점 자체가 아니라 **"누구의 어떤 문제를 푸는가"**로 바꾸는 것이 핵심입니다.

| 지금 표현 | 제안으로 바꾼 표현 |
| --- | --- |
| | |

## 2단계 · 쌓기

### 03. 권위 성장 전략

```
팔로워가 한 명도 없어도, 무료 콘텐츠와 사회적 증거를 활용해서
[분야]에서 권위를 쌓는 3가지 전략을 알려줘.
```

> 🎯 **핵심 포인트** — 팔로워 수가 적다고 전문성을 못 보여주는 게 아닙니다. **내가 이미 가지고 있는 증거**부터 콘텐츠로 쓰세요.

| 이미 가진 증거 | 예 |
| --- | --- |
| 내 경험 | 3년간 이 일을 하며 겪은 것 |
| 실제 사례 | 도와준 사람의 이야기 |
| 전후 변화 | 바뀌기 전 / 바뀐 후 |
| 후기 | 받은 감사 메시지 |
| 결과물 | 실제로 만든 것 |

### 04. 니치 네트워크 만들기

```
내 분야 사람 5명과 연결될 수 있는 주간 실행 계획을 만들어줘.
DM 스크립트, 가치 중심의 아웃리치 아이디어, 그리고 후속 연락 주기까지 포함해줘.
```

> 🎯 **핵심 포인트** — 콘텐츠만 올리고 기다리지 말고, **사람들과 연결되는 행동**도 함께 만드세요. 중요한 건 무작정 "친해지고 싶어요"가 아니라 **상대에게 먼저 줄 수 있는 가치**를 생각하는 것입니다.

### 05. 반복하고 강화하기

```
위의 모든 내용을 바탕으로, 번아웃 없이 평판, 노출, 신뢰도를 키울 수 있는
주간 반복 루틴을 만들어줘.
```

> 🎯 **핵심 포인트** — 브랜딩은 **한 번의 바이럴보다 반복해서 같은 인식을 쌓는 것**에 가깝습니다.

## 3단계 · 강화하기

### 06. 시그니처 콘텐츠 만들기

```
내 분야가 [분야]일 때, 사람들이 나를 떠올리게 만드는 시그니처 콘텐츠 주제 5개를 만들어줘.
각 주제마다 반복 가능한 콘텐츠 포맷, 첫 문장 후킹, 예시 제목 10개,
그리고 팔로워가 저장하고 싶어지는 이유까지 정리해줘.
```

> 🎯 **핵심 포인트** — 매번 새 주제를 찾는 것보다 **"이 주제 하면 이 사람"**이라는 인식을 만드는 게 중요합니다. 5개를 정했다면 **그 안에서 사례와 각도만 바꿔 반복**하세요.

### 07. 경쟁 계정 분석하기

```
[분야]에서 이미 잘 되고 있는 계정 5개를 분석한다고 가정하고,
그들이 성장한 이유를 콘텐츠 주제, 후킹 방식, 말투, 반복 포맷, CTA, 신뢰 요소 기준으로 분석해줘.
그리고 내가 따라 할 수 있는 차별화 전략 5가지를 제안해줘.
```

> 🔍 **TIP** — 가능하면 실제 분석하고 싶은 계정의 **프로필 소개 / 인기 게시물 / 게시물 제목 / 조회수 / 댓글 반응**을 GPT에 함께 입력하세요. 훨씬 구체적인 분석을 받을 수 있습니다.

> ⚠️ **주의** — 자료를 넣지 않고 "가정하고 분석해줘"라고만 하면 AI가 **없는 계정과 없는 수치를 지어낼 수 있습니다.** 나온 계정명·숫자를 그대로 믿지 말고, 실제 자료를 넣어 다시 분석시키세요.

### 08. 저장되는 콘텐츠 만들기

```
[분야]에서 사람들이 저장하고 싶어지는 콘텐츠 아이디어 30개를 만들어줘.
각 아이디어는 체크리스트형, 실수 모음형, 비교형, 템플릿형, 단계별 가이드형으로 나눠주고,
제목과 첫 문장 후킹까지 함께 작성해줘.
```

**저장을 만드는 대표 포맷 5가지**

| 포맷 | 왜 저장하나 |
| --- | --- |
| 체크리스트 | 나중에 하나씩 확인하려고 |
| 실수 모음 | 나도 안 하려고 |
| 비교 | 고를 때 다시 보려고 |
| 템플릿 | 그대로 쓰려고 |
| 단계별 가이드 | 순서대로 따라 하려고 |

> 🎯 **핵심** — "좋은 정보다"에서 끝나는 것보다 **"나중에 다시 봐야겠다"**는 생각이 드는 콘텐츠를 만드세요.

> 🔗 저장되는 콘텐츠의 **표지·제목**은 [[01강_저장되는 카드뉴스 표지 공식]]과 함께 보세요.

## 4단계 · 연결하기

### 09. 내 경험을 콘텐츠 자산으로 바꾸기

```
내 경험은 [경험 입력]이야.
이 경험을 사람들이 공감하고 신뢰할 수 있는 콘텐츠로 바꿔줘.
실패담, 깨달음, 전후 변화, 배운 점, 조언형 콘텐츠로 각각 변환하고,
릴스 제목 10개와 카드뉴스 제목 10개를 만들어줘.
```

> 🎯 **핵심 포인트** — 소재가 없다고 느껴질 때는 새 정보를 찾기 전에 **내가 이미 겪은 경험**을 먼저 꺼내세요. **같은 경험 하나도 관점을 바꾸면 여러 개의 콘텐츠가 됩니다.**

**경험 하나 → 콘텐츠 5개**

| 관점 | 예 (같은 경험, 다른 각도) |
| --- | --- |
| 실패담 | "이렇게 하다 3개월을 날렸습니다" |
| 깨달음 | "그때 알았더라면 좋았을 한 가지" |
| 전후 변화 | "바꾸기 전 vs 바꾼 후" |
| 배운 점 | "이 일에서 배운 3가지" |
| 조언형 | "지금 시작하는 분께 드리는 말" |

#### ✏️ 내 경험 꺼내기

| 항목 | 내 답 |
| --- | --- |
| 꺼낼 경험 하나 | |
| 실패담 각도 제목 | |
| 전후 변화 각도 제목 | |
| 조언형 각도 제목 | |

### 10. 수익화 연결 콘텐츠 만들기

```
내가 판매하고 싶은 상품/서비스는 [상품 입력]이야.
이걸 대놓고 팔지 않고, 자연스럽게 관심과 문의로 연결되는 콘텐츠 아이디어 20개를 만들어줘.
각 콘텐츠마다 문제 제기, 공감 포인트, 해결 방향, 부드러운 CTA까지 작성해줘.
```

> 🎯 **핵심 포인트** — 콘텐츠와 판매를 완전히 분리하지 마세요. 이 흐름을 콘텐츠 안에 자연스럽게 녹이면 정보를 주면서도 수익화로 연결됩니다.

```
문제 인식 → 공감 → 해결 가능성 → 내 상품·서비스
```

## PART 5. 결과가 마음에 안 들 때

처음부터 다시 질문하지 마세요. **추가 지시를 이어서** 주는 게 훨씬 빠릅니다.

| 이럴 때 | 이렇게 말하세요 |
| --- | --- |
| 뻔한 답이 나옴 | 너무 일반적이야. 내 경험과 강점이 더 드러나게 수정해줘. |
| 아무도 안 찾을 주제 | 사람들이 실제로 검색하거나 저장할 만한 주제로 더 구체화해줘. |
| 어디서 본 듯한 주제 | 흔한 콘텐츠는 제외하고 내가 직접 경험한 사람만 쓸 수 있는 주제로 바꿔줘. |

## ⚠️ 함께 지킬 것

**1. AI가 내 경력을 지어내게 두지 마세요.** 시작 프롬프트의 "정보가 부족하면 임의로 가정하지 말고 나에게 먼저 질문해줘"를 반드시 넣으세요. 없는 경력으로 만든 포지셔닝은 처음 질문받는 순간 무너집니다.

**2. 07번 경쟁 분석의 계정명·수치는 확인하세요.** 자료를 넣지 않으면 AI가 그럴듯한 계정과 숫자를 만들어냅니다.

**3. 10번 수익화 콘텐츠도 광고입니다.** 대가를 받은 콘텐츠라면 표시가 필요합니다.

**4. AI는 나를 유명하게 만들어주지 않습니다.** 이 자료의 결론입니다.

> **GPT가 나를 유명하게 만들어주는 것이 아니라, GPT를 이용해 '나를 어떤 사람으로 기억시킬지'를 반복해서 설계하는 것입니다.**
