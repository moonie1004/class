# 마케팅강의 - 전체목차

블로그·클로드 강의와 별도로, **콘텐츠 마케팅 실무**를 다루는 자료를 모으는 폴더입니다. 인스타그램·릴스·카드뉴스처럼 채널을 가리지 않고 통하는 원리를 중심으로 정리합니다.

## 강의 목록

1. [[01강_저장되는 카드뉴스 표지 공식]] — 표지 5법칙 + 25개 바이럴 후킹 공식 + 슬라이드 프레임워크 + 업로드 전 3초 테스트
2. [[02강_내 분야에서 기억되는 브랜딩 프롬프트 10]] — 포지셔닝부터 수익화까지 4단계 GPT 프롬프트 10종

> 3강부터는 준비되는 대로 이어서 추가합니다.

**1강과 2강은 이렇게 이어집니다** — 2강에서 *무엇을 만들지*(포지셔닝·시그니처 주제·저장되는 아이디어 30개)를 정하고, 1강으로 *어떻게 보이게 할지*(표지·제목)를 만듭니다.

---

## 이 폴더의 관점

**표지(첫인상)가 도달의 대부분을 결정한다** — 이 원리는 채널을 가리지 않습니다.

| 채널 | 표지에 해당하는 것 |
| --- | --- |
| 인스타 카드뉴스 | 1번 슬라이드 |
| 릴스·유튜브 | 썸네일 + 첫 1초 |
| 블로그 | 제목 + 대표사진 |
| 상세페이지 | 첫 화면 |
| 뉴스레터 | 메일 제목 |
